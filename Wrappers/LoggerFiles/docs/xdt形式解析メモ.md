# KEYENCE NR-500 xdt ファイル形式(解析結果 2026-11-02)

対象: `AS110NoiseTest/2026.06.12_不具合返却品/**/*.xdt`(360ファイル、各39,032バイト)で確認。

## ヘッダ
- 0x00: `"NR500P.DAT"`(マジック)
- 0x44: `"NR-500"`(機種名)
- 0x58: FILETIME(u64, 測定日時。例 2026-06-12 13:26:48)
- 0x68: u32 サンプル数(=2000)
- 0x31C 以降: チャンネル定義が 0x44 バイト間隔で並ぶ(cp932 文字列)
  - 名前: 電流(mA) / 供給圧力(kPa) / 制御圧力(kPa) / 50L排気(東京ﾒｰﾀ) / 横穴圧力 / 変位計 / Voltage08 / Current01〜04
  - 名前+0x20: float 入力電圧、+0x24: float 物理量 → 比が換算係数
    - 電流: 1.0V → 6.0mA(×6)
    - 供給圧力: 4.4V → 440kPa(×100)
    - 制御圧力: 4.394V → 439.4kPa(×100)

## 表示レンジ(波形ウィンドウの縦軸。2026-11-03 追加)
LOGGER で開いたときの縦軸の上限・下限はファイルに保存されている。アプリが保存した xdt は雛形(10mA、74〜84 kPa)のままなので
別の電流では制御圧力の線が画面の外に出る。人が測ったファイルは「収集中オートスケール」で中心 ≈ 測定値(0.5 kPa 刻み)・幅 10 kPa。
- 0x17D0 から 0x30 バイトごとに **波形ウィンドウ 1** のチャンネル表示ブロックが CH1, CH2, CH3, (CH4) の順
  - +0x00 u32 線の色、**+0x04 float 上限、+0x08 float 下限**、+0x0C u32 60、+0x10 u32 40 or 50、+0x24 u16 有効(1)、+0x26 u16 CH 番号(1 始まり。CH4 のブロックは 0)
  - 人のファイル: CH1 ±5.5、CH2 445/435、CH3 測定値中心 ±5、CH4 3/0
- 0x1914 から同じ並びで **波形ウィンドウ 2**(供給圧力を出している方): CH1 ±33、CH2 445/435、CH3 ±549.875(既定のまま)、CH4 ±5
- 学習データ・試験データの 507 本(旧 LOGGER 形式、署名 0x10 = 03 00 03 00)すべてで同じ位置・同じ CH 番号を確認
- アプリは保存後に `Conversion/XdtDisplayRange.cs` でウィンドウ 1 の CH3 の上限・下限を「幅そのまま、中心 = 平均値の 0.5 kPa 丸め」に書き換える(人のファイル 48 本に同じ処理をかけると 42 本は無変更、6 本は中心が 0.5 ずれるだけ)。既存ファイルは `MeasurementCheck --fix-display <フォルダ>` で直せる

## データブロック(0x1B38 から)
```
u32 N        サンプル数(2000)
u32 C        記録チャンネル数(4)
u32 0        パディング
u32 idx[C]   チャンネル番号 0,1,2,3
float32 data[N][C]   サンプル優先のインターリーブ、単位は V
```
末尾に 28 バイトのトレーラ。

記録チャンネル順: ch0=電流(×6→mA)、ch1=供給圧力(×100→kPa)、ch2=制御圧力(×100→kPa)、ch3=不明(電流に近い値、約1.66V)。

## 検証
`(max-min)×100` を ch2 で計算した値が、`AS110-035_不具合返却品.xlsx` の「制御圧力PP値」と全サンプル(SN60226 / SN60260 / SN60256再調整後)で小数1桁まで完全一致。
→ 人が LOGGER 画面で読んでいた p-p 値は、xdt の制御圧力チャンネルの単純 max-min。

## 汎用パーサ方針
固定オフセットに頼らず、`[N][C][0][0..C-1]` のパターンを 0x1000 以降で探索して先頭を特定すると、チャンネル数や設定が変わっても読める(動作確認済み)。

## 補足
- ファイル名規則: `AS110_035_<説明>_<SN>_<mA>mA_20ms_440kPa.xdt`(20ms=サンプリング周期、2000点=40秒)
- 7351x.pdf はカタログ(8ページ)。7351E の USB は ADC/R64 系コマンド(SCPI は GPIB のみ)。USB が仮想COM / USBTMC / 専用DLL のどれで見えるかはカタログからは不明。要確認。
