# AS110AllCheck 仕様(2026-11-05 移植時に整理)

移植前のリポジトリ AS110AllCheck(`9.2252.33f.6`、2026-11-02)の README・コードの動きを、雛形の形にまとめ直したもの。移植前に使われていた動きはそのまま残した。**移植時に人と決めたこと**は「移植で決めたこと」に分けて書く。操作の細部は `Apps/AS110AllCheck/README.md`「操作・設定」と `Apps/AS110AllCheck/docs/operation.md` が正本。

- 状態: **移植前の動きのまま移した**(2026-11-05)。ビルドと機器なしの検査まで。実機では未確認(`Apps/AS110AllCheck/README.md`「確認」)

## 目的

AS110 の動き検査・データ調整・データ取りを 1 つのアプリで行う。データ取りでは、測定 → Excel 雛形への転送と合否判定 → 正式保存(Excel・PDF・LOGGER)→ 漏れチェック → 完了(S/N 管理)までを、PC と M5Stack のボタンで進める。

## 使う機器

| 機器 | 役割 | 接続 | 使う wrapper |
|---|---|---|---|
| M5Stack Basic V2..(スケッチ `firmware/AS110M5Stack`) | 現場の操作ボタン A/B/C・状態表示・外部接点(動き検査の開始条件) | USB シリアル | `Wrappers/Arduino`(取り決めはアプリの `As110ArduinoProtocol`) |
| NF WF19.3 / SIGLENT SDG1032X | バースト出力(動き検査・データ取り)、漏れ試験の DC +5V | USB(VISA) | `Wrappers/Instruments` の `FunctionGeneratorConnection`・`Wf19.3BurstSession`・`Sdg1032XSession` |
| KEYENCE NR-500 / NR-X | データロガー。雛形・参照波形の読み込み、測定、一時保存、正式保存 | NR-500: USB。NR-X: **USB と Wi-Fi**(画面で選ぶ) | `Wrappers/WaveLogger.Automation`、`Wrappers/Common`(本体確認・Wi-Fi 切替) |
| Microsoft Excel | 作業ブック(雛形.xlsx)への転送、判定セルの読み取り、保存・PDF | PC | `Wrappers/Excel` |

## 入力

- モード(動き検査・データ調整・データ取り)→ 校正値 → 型式(参照波形)の順(2026-11-06 にスタンド選択を廃止。「校正の流れの変更」)。データ取りは モード → **保存先** → 校正値 → 型式 → 測定開始 S/N の順(「データ取りの順番」)
- NR-500 の xdt では、モード選択後(データ取りは保存先の選択後)に自動で開く校正画面で電流・圧力の 2 点校正(. 項目)を入れる
- 雛形: `雛形/` の LOGGER 雛形(xdt / ydt)・参照波形(xyb)・Excel 雛形(雛形.xlsx)。exe の隣の `雛形` フォルダーを人が差し替える
- 転送設定(CH・圧縮点数・NR-X の CSV 列・点数・シート・セル・保存先): `%LOCALAPPDATA%\AS110BoltCheck\ver3.json`
- NR-X の Wi-Fi プロファイル(SSID・IP): `As110/As110ConnectionSettings.cs`

## 出力

- 正式保存: Excel(作業ブックの別名保存)・PDF(シート「圧縮5」)・LOGGER のファイル。保存先は転送設定
- 完了記録: 保存先の `完了記録.txt`
- 校正記録: データ取りの保存先の `校正記録\校正_yyyy-MM-dd_HH-mm-ss.txt`(2026-11-06 まで `%LOCALAPPDATA%\AS110AllCheck\校正記録.txt`)
- 診断ログ: exe の隣の `Logs`(書けなければ `%LOCALAPPDATA%\AS110AllCheck\Logs`)

## 移植で決めたこと(2026-11-05、人の判断)

1. NR-X は **USB と Wi-Fi の両方を残す**(今のまま)。Wi-Fi の SSID・IP は**アプリの設定クラス**(`As110/As110ConnectionSettings.cs` の `NrWifiProfiles`)に置く。共通の設定ファイルにはしない(同じ NR-X を別のアプリでも Wi-Fi で使うと、SSID が変わったときに複数か所を直すことになる)
2. 発行の設定は「**データ調整verX.YY**」(版つき。2026-11-09 に ver2.01、2026-11-10 に ver2.02、2026-11-11 に ver2.03 を発行、次は ver2.04)と、ふつうの発行(`FolderProfile`、`AS110AllCheck.exe`)の 2 つを残す。旧プロトタイプ ver1・ver2 の設定は移さない
3. 診断ログの代わりの保存先のフォルダー名を **AS110AllCheck** に変える(移植前は `AS110BoltCheck`)。転送設定 `ver3.json` の場所は変えない(現場 PC の保存先設定を引き継ぐため。人に確認はしていない)

## 校正の流れの変更(2026-11-06、人の判断。承認済み・実装済み、実機は未確認)

スタンド選択ボタンをやめ、モードを選んだらそのまま校正値の入力画面を出す。校正値は人が毎回入れる(校正は肝心要なので、前回値を呼び出さない)。

### 決まったこと

1. **スタンド選択をやめる**。`As110StandSettings` の 3 スタンド(４方弁用・門馬さんの隣・増産用)と選択ボタンは画面から消す
2. **流れ**: 接続確認 → モード選択 → **校正画面が自動で開く** → 適用 → 型式(参照波形)選択 → 測定。モードを選んだ時点で接続確認が終わっていなければ、接続確認が終わった時点で開く。データ取りは保存先を選んでから開く(下の「データ取りの順番」)
3. **校正画面の初期値**は、そのモードの雛形(xdt)に入っている値をそのまま出す(電流 CH1・圧力 CH2 の 2 点ずつ . 項目)。前回の適用値は呼び出さない(今の雛形 `AS110データ調整・データ取り用.xdt` は電流 -0.002 V=0.01 mA / 0.993 V=30 mA、圧力 -0.001 V=0 kPa / 5.524 V=540 kPa)。校正画面の並びは現場の校正記録用紙と同じ縦型: 「電流」「圧力」の枠ごとに 1(低点)・2(高点)の行、左が計測値(V)・右が表示値(mA / kPa)(2026-11-06、人の指示)
4. 校正画面をキャンセルしたときのために、「校正値を入力・変更」ボタンを 1 つ残す(今の「電流・圧力の校正値を変更」と同じ場所・同じ条件。適用後の入れ直しもこのボタン)
5. **横軸拡大(門馬さんの隣のスタンドだけ 2 段)はやめる**。参照波形を読んだあとの LOGGER の横軸は雛形のまま。必要なら人が LOGGER の画面で拡大する
6. **校正記録**は、データ取りの保存先の中に日付と時刻つきのテキストで残す(下の「校正記録の置き場」)
.. **NR-X(ydt)は保留**。NR-X はまだ実機確認していないので、校正画面は今までどおり出さず、ydt の雛形の値のまま使う。画面に「NR-X の校正は未対応(雛形の値のまま)」と出す。NR-X の校正対応は宿題のまま(`Apps/AS110AllCheck/docs/xdt-calibration.md`)

### 変えないこと

- 本体の判定順(NR-500 → NR-X)、ソフトの既定(旧 WAVE LOGGER → X)、接続の既定(USB)。今のコードのまま
- 校正画面の . 項目・入力のきまり(小数点 `.`、高点 > 低点)、適用時に作業用 xdt を作って LOGGER へ読み込む動き
- 記録を保存できないときは設定完了にせず、測定を始めさせない

### 校正記録の置き場(2026-11-06 決定: 保存先のみ)

- データ取りの**保存先フォルダーの中の `校正記録` フォルダー**に、適用した校正値を 1 件 1 ファイルで残す。exe の隣には置かない(人の指示)
- ファイル名は適用日時 `校正_yyyy-MM-dd_HH-mm-ss.txt`。中身は人が読める日本語テキスト(適用日時・モード・本体・雛形ファイル名・電流 2 点・圧力 2 点)、UTF-.
- 書く時点: **校正の適用と、この起動での保存先の選択の両方がそろった時点**で書く(データ取りでは保存先を選んでから校正するので、ふつうは校正の適用時)。その後に校正を入れ直したとき、保存先を選び直したときも、そのつど書く(同じ適用でも保存先ごとに 1 件残る)。前回の起動の保存先には書かない
- データ調整モードは保存先が無いので残らない。NR-X(ydt)は校正しないので残らない
- 書けないとき(保存先に書き込めない等): エラーを表示する。校正の入れ直しで書けなければ設定完了にせず測定を始めさせない。保存先の選択で書けなければ保存先を未選択のままにする
- 今の `%LOCALAPPDATA%\AS110AllCheck\校正記録.txt`(1 行 1 JSON)への追記はやめる。過去のファイルは消さない

### データ取りの順番(2026-11-06、人の指摘。実装済み、実機は未確認)

データ取りでモードを選ぶと先に校正画面が開き、保存先はその後に選ぶ順になっていた。校正記録は保存先に書くので、保存先を先に決める。

- **流れ**: 接続確認 → モード「データ取り」→ **「保存先選択」で保存先を選ぶ** → 校正画面が自動で開く → 適用 → 型式(参照波形)→ 測定開始 S/N → 測定。保存先を選ぶまで校正画面は開かず、「校正値を入力」ボタンも押せない。「次にすること」と校正欄に「「保存先選択」で保存先を選んでください」と出す
- **保存先は起動のたびに空から始める**。前回の保存先(転送設定 `ver3.json`)は、選択画面の最初に開くフォルダーにだけ使う。前回の保存先を入れたままにすると、校正を適用した時点で前回のロットのフォルダーへ校正記録が書かれ、そのフォルダーが無い(USB を抜いた等)と保存先を選ぶ前に校正が止まっていた
- 転送設定の「保存先フォルダ」を書き換えて保存したときも、「保存先選択」で選んだのと同じ扱い(変えていなければ何もしない)
- データ調整・動き検査は保存先が無いので、今までどおりモードを選んだら校正画面が開く。データ調整で校正を済ませてからデータ取りへ移ったときは、保存先を選んだ時点で校正記録を書く(校正は入れ直さない)
- 1 回の起動で保存先を選んだあとにモードを行き来しても、選び直しは要らない(同じ保存先には校正記録を 2 回書かない)
