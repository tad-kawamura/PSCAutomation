# AS110NoiseTest 仕様(2026-11-04 移植時に整理)

移植前のリポジトリ AS110NoiseTest(`c3e75b3`、2026-11-03)の `CLAUDE.md` に書かれていた決定事項を、雛形の形にまとめ直したもの。内容は移植前に人と決めて実装・実機確認まで済んでいる(このファイルで新しく決めたことは無い)。経緯の詳しい記録は `Apps/AS110NoiseTest/docs/`。

- 状態: 測定シーケンスまで実装済み。**設定画面(WinForms)は未着手**で、今は確認ツール `Tools/MeasurementCheck` で測る
- 現場にはまだ投入していない(2026-11-04 時点)

## 目的

AS110 のノイズ測定を自動化する。人が LOGGER 画面で電流を変えながら制御圧力の p-p を読み、Excel に転記していた作業を、開始ボタン 1 つで最後の電流まで自動で行う。

WF1973 で電流を段階的に変え、ADCMT 7351E の実測で ±0.1mA に合わせてから、NR-500(WAVE LOGGER)で xdt を記録・保存し、制御圧力の p-p と合否(黄・赤)を Excel に書く。

## 使う機器

| 機器 | 役割 | 接続 | 使う wrapper |
|---|---|---|---|
| WF1973 | 発振器。DC オフセットで電流を指令する(**1V = 6mA**) | USB(VISA) | `Wrappers/Instruments` の `Wf1973DcSource` |
| ADCMT 7351E | DMM。実電流を読む | **USB のみ**(USBTMC として VISA。GPIB / RS-232C 不可) | `Wrappers/Instruments` の `Adcmt7351ESession` |
| KEYENCE NR-500 | データロガー。記録は xdt | USB。**旧 WAVE LOGGER(4.03.00)で使う**(実機 PC には X 2.00.10 も入っているが、NR-500 は旧で測る) | `Wrappers/WaveLogger.Automation`(アプリの `Measurement/WaveLoggerDevice.cs` 経由) |
| Excel | 結果ブックへの書き込み | 同じ PC | `Wrappers/Excel`(アプリの `Excel/NoiseResultWorkbook.cs` 経由) |

- NR-X は使わない(対象ファイルは **xdt のみ**。ydt は対象外。将来変わる可能性あり)
- 7351E: 値は `DCI_ +006.027E-03` 形式(約 400ms/回)。設定は ADC コマンド(SCPI 不可)。既定は DCI・200mA 固定・SLOW2・**BUS トリガ**(読むたびに `*TRG`、捨て読み不要)。詳細は `Wrappers/Instruments/docs/7351E実機確認.md`
- LOGGER のチャンネル(1 始まり): **CH1 = 電流、CH2 = 供給圧力、CH3 = 制御圧力、CH4 = WF1973 の指令電圧**(1V = 6mA、スケーリングなし。2026-11-03 の実機で CH1 と同じ値を示して判明)

## 入力

- SN、備忘録
- 開始 mA / 刻み mA / 終了 mA(可変。整数 mA だけ。雛形 Excel の列が 1〜35 の整数のため)
- 保存先(xdt)
- 結果 Excel(新規作成か、既存ブックへの追記か。日をまたぐため両方)
- 雛形: `雛形/AS110ノイズ測定用.xdt`(記録設定)、`雛形/AS110ノイズ測定_雛形.xlsx`(結果ブック)。exe の隣の `雛形` フォルダーに置き、exe には入れない

## 出力

- xdt: 1 電流 1 本。ファイル名の既定は `AS110_035_<備忘録>_<SN>_<mA>mA_20ms_440kPa.xdt`(同名があれば `_2`)
- 保存した xdt の制御圧力の表示レンジを平均値中心に直す(雛形のままだと LOGGER で開いたとき線が画面外に出る)。直せなくても測定は止めない
- Excel(雛形から作ったブック。構成は `Apps/AS110NoiseTest/雛形/README.md`)
  1. 測定値の書き込み: `PP値`(p-p、0.1 kPa 丸め)・`平均値`(0.01 kPa 丸め)・`赤判定`(赤なら「赤」)の同じ行・同じ列、`詳細` の末尾に 1 行(全チャンネルの mean / p-p、赤の根拠、xdt ファイル名)
  2. 行の決め方: `PP値` で **SN と備忘録が同じ行**があればその行(上書き)、無ければ SN が空の最初の行。日付はキーにしない。雛形の 100 行を超えたら上の行をコピーして同じ形にする
  3. 書き換え: 図形の中の文字は使わない。セルに書くだけ
  4. 判定の読み取り: `PP値` の数式(最大 p-p・黄の数・赤の数・判定)を再計算して読み、画面・ログに出す。合否はアプリ側の判定(下記)で決まり、Excel の計算は表示用
  5. 保存: 開いたブックへ上書き保存(新規のときは雛形をコピーしてから開く)。合否にかかわらず保存する
  6. PDF: 作らない
  7. 終わったら: 既定は閉じる。`--visible` で処理中も見せ、`--leave-open` で終わったあと人に渡す
  - 設定シートに、アプリが実際に使った判定しきい値を書く

## 手順

開始後は最後の電流まで自動:

`OpenFile(雛形 xdt)` → WF1973 オフセット設定 → 7351E の実測で ±0.1mA に収まるまでフィードバック → 待ち(1 秒) → `StartSingleAcquisition()` → `GetState()` で停止を待つ → `SaveXdt(規則名)` → xdt を読んで p-p を計算・判定 → Excel に書く → xdt の表示レンジを直す → 次の電流

- 開始前は、最初の電流に合わせるまで出力 OFF
- 記録中(約 40 秒)は WF1973 の指令を固定する。±0.1mA を満たす必要があるのは合わせ込み完了(記録開始前)の時点だけ
- シーケンスは専用の STA スレッドで動かす(`docs/測定シーケンス実機確認.md`「スレッド」)

## 異常時

- 機器が見つからない(WF1973・7351E・NR-500・LOGGER・Excel): 測定を始めずにメッセージで止める
- 電流が合わない・上限を超える指令になる: その時点で止め、出力 OFF にする(上限 **35mA** を超える指令は出さない)
- 人が中断した: LOGGER を停止し、WF1973 を 0V・出力 OFF にする(実機確認済み)
- 結果ブックが読み取り専用で開かれた(ほかで開いている): 止める
- 雛形に無い mA(小数の刻みなど): 例外にする(必要になったら列を挿入する仕様にする)
- 注意: PC がスリープから復帰すると WF1973 の USBTMC が固まることがある(USB の抜き差しで復旧)。測定 PC はスリープを切る

## 細部

- 電流の許容: 目標 **±0.1mA**、上限 **35mA**。電流を合わせてから記録開始までの待ち: **1 秒**(設定値)
- p-p は **CH3 制御圧力の max − min**(xdt の V 値 ×100 → kPa)。人が LOGGER 画面で読んでいた値と一致
- 合否は 2 段階(しきい値は `Analysis/NoiseJudgeSettings.cs` に集約し、コードに直書きしない):
  - **黄** = p-p ≥ 1.4 kPa(0.1 kPa に丸めて比較)
  - **赤** = 矩形波的な変動(台地: 中央値から 0.4 kPa 以上が 15 サンプル連続 / 低周波・高周波のパワー比 ≥ 7.8 / 隣接 2 秒平均の段差 ≥ 0.35 kPa かつ t ≥ 6)
  - 学習データ 426 件(2 データセット)すべてで人の判定と一致(`docs/赤判定規則メモ.md`)。SN60256 フレキ ASSY 交換後の 10/27mA は本人確認で赤にしないと決定
- 主表は制御圧力。供給圧力(CH2)も後で欲しくなる可能性があるので、全チャンネルの mean / p-p は詳細シートに残す
