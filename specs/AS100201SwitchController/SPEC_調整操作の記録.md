# AS100201SwitchController 追加仕様: 調整操作の記録(学習モード)

AS100-201 の流量調整で、熟練者が「測定結果を見て何をしたか」を記録し、あとで AI に判断を学習させるためのデータ(測定 → 操作 → 測定の三つ組)を貯める仕組み。既存のスイッチ制御アプリ(`Apps/AS100201SwitchController`)に**学習モード**として足す。

- 状態: **承認済み・PC 側は実装済み・タッチパネルのスケッチは版 1(2026-11-13、横置き・仮レイアウト、ビルドのみ)・実機未確認**(2026-11-09 に人が承認。同日、PC 側を実装し模擬テスト 6 グループを追加(`Apps/AS100201SwitchController/Learning/`、確認した範囲と未確認は `Apps/AS100201SwitchController/README.md`「学習モード」)。保存先は雛形と同じフォルダー、xdt は日時_側の名前に同日決定。タッチパネルは同日 M5Stack Tab5 に決定、スケッチはこれから)。相談で決める項目(「未定」)は同日の 3 回目で全部決まり、同日に承認された。「いずれ決める」の項目は試作しながら決める。2026-11-10 に人の決定で、学習モードは決まった雛形を自動で読み込み、保存先を exe の隣の `学習データ\`(台帳は 1 つ、xdt は日付フォルダー)に変えた(「決めたこと」の「雛形と保存先(2026-11-10 変更)」)
- 本体の仕様は [SPEC.md](SPEC.md)。この文書は追加分だけを書く
- 「決めたこと」は 2026-11-09 の相談で人が決めた内容(3 回に分けて決めた)。「未定」は人の判断待ち(3 回目でなくなった)。「いずれ決める」は試作しながら決めると人が決めた項目。残っていること全体(仕様決め・機器・実装・確認・学習側)はトピックだけを末尾の「残課題」にまとめた

## 背景と目的

- AS100-201 は圧縮空気を使うノズルフラッパ式の 3 方弁。流量の大きさはノズルとフラッパの距離、特性の傾きはアマチュアとヨークのエアギャップと磁力で決まる。これらが互いに影響するため、調整は熟練者が測定波形を見ながら判断している
- 調整手順(`学習データ/⑩_2025.06.06_SN091-/AS100-201_調整手順.xlsx`、同 `.pptx`。学習データは作業 PC のローカルにあり、リポジトリには入れない)にはおおまかな規則(立ち上がり電流 PC 3.75mA / CR 9.5mA、最大流量の目標、減磁すると立ち上がりが右にずれる、など)があるが、部品の公差で効き方が変わるので「規則はあってないようなもの」(人の説明)
- 過去の測定データ(SN001〜SN154、xdt 約 1,100 本)は結果だけで、**その間に作業者が何をしたかの記録がない**。また**調整中の波形は今は保存していない**(最終結果だけ残している。人の回答)。学習には「操作前の測定」「操作」「操作後の測定」の対が要る
- この追加仕様は、作業者が操作するたびにタッチパネルのボタンを押すだけで、その対が自動で残るようにする。**将来の AI による判断の提案・自動調整は対象外**(データが貯まってから別に決める)

## モード

| モード | 内容 |
|---|---|
| 通常モード | 今のアプリの動きそのまま(スイッチで WF1973 の位相出し直しと LOGGER の開始・停止。保存は LOGGER 任せ)。**変えない** |
| 学習モード | 通常モードの動きに加えて、タッチパネルで操作を記録し、測定のたびに xdt を保存し、CSV 台帳に 1 行 1 出来事を追記する。**タッチパネルがつながっていないと動かない**(人の回答「学習モードのときにタッチパネルがつながっていないなら動かなくていい」) |

- モードの切り替え方: **起動時に選ぶ**(2026-11-09、人の回答)。起動すると「通常モード / 学習モード」を選ぶ窓を出し、選んでから接続確認を始める。途中で変えるには再起動する。初期選択は通常モードで、窓を × で閉じたときも通常モード(今までと同じ動きになる。AI の提案、異論があれば変える)
- 学習モード中は、ウィンドウのタイトルと画面上部に「学習モード」と出し、起動時のログにも残す

## 記録の考え方

- 1 個体の調整は「測定 → 操作 → 測定 → 操作 → … → 測定 → 完了」の列。アプリは **1 行 1 出来事** で CSV 台帳に追記する(出来事 = 測定、操作、完了、取消)
- 三つ組はあとから台帳を読めば組める: ある操作の「前の測定」は直前の測定の行、「後の測定」は直後の測定の行
- PC 側 / CR 側 は、測定の前に押された PC_go / CR_go(今のスイッチ)から分かる。**作業者が側を入力する必要はない**
- 個体の区切り: 完了の行から次の測定の行まで。完了のあとに操作の行が来たら、完了は取り消されたものとして同じ個体が続く
- 立ち上がり電流・最大流量などの特徴量は、**この追加仕様では計算しない**。xdt をそのまま残し、台帳からたどれるようにする。特徴量の定義(立ち上がりをどう読むか)は学習の段階で決めて、別の処理で xdt から計算する(xdt の読み取りは既存の部品 `Wrappers/LoggerFiles` でできる)

## 出力(学習モードのとき)

### xdt の保存

- LOGGER が停止したとき(sw4、または操作ボタンによる停止)に、アプリが `SaveXdt` で保存先の日付フォルダー(exe の隣の `学習データ\yyyyMMdd\`。2026-11-10 変更、それまでは雛形と同じフォルダー)へ保存する。ファイル名は `yyyyMMdd_HHmmss_<側>.xdt`(2026-11-09 決定。台帳の行と 1 対 1)。実装では、停止直後はデータの読み出し中のことがあるため、測定の行を止めた時点で書き、xdt は LOGGER の状態が停止に戻った時点で保存する。sw4 を押さずに LOGGER が自分で止まったときも、停止に戻った時点で行と xdt を残す(停止のきっかけ「LOGGER の停止」)
- 通常モードでは保存しない(今までどおり)

### CSV 台帳(1 行 1 出来事)

- 形式: CSV(UTF-8 BOM 付き、ヘッダー行あり、1 行 1 出来事)。置き場は exe の隣の `学習データ\調整記録.csv`(1 つ。2026-11-10 変更。それまでは雛形のフォルダー)
- 列(案)

  | 列 | 内容 |
  |---|---|
  | 日時 | PC の時刻(秒まで) |
  | 種類 | 測定 / 操作 / 完了 / 取消 / 押した(2026-11-12 追加・実装、実機未確認。PC_go / CR_go を押すたびの行。`SPEC_測定中の取り込み.md`「押した瞬間の記録」) |
  | 側 | PC / CR(測定の行。直前に押された PC_go / CR_go。2 回押しなら「PC(2 回押し)」のように残す) |
  | 位相 | 測定の行。そのとき WF1973 に送った位相(°) |
  | 停止のきっかけ | 測定の行。sw4 / 操作ボタン(掃引の途中で止めた) |
  | 操作 | 着磁 / 減磁 / ノズル P / ノズル R / スペーサー P / スペーサー R(操作の行) |
  | 方向 | 押し込む / 外に出す / 上げる / 下げる(操作の行) |
  | 程度 | 微調整 / 普通 / 大きく(ノズル)、しっかり / ちょんちょん(減磁) |

- 台帳や xdt に書けなかったときはログと最前面のメッセージボックス

## 手順(学習モードの 1 個体の流れ)

1. 起動すると「通常モード / 学習モード」を選ぶ窓が出る。学習モードを選ぶと接続確認にタッチパネルの確認が加わる(見つからなければ動かない)。通常モードを選べば今までどおり
2. 接続確認が通ると、アプリが決まった雛形を自動で読み込む(2026-11-10。それまではドロップ)
3. 作業者が PC_go(または CR_go)→ F8 で測定、見終わったら sw4 で停止(既存)。停止後、アプリは xdt を保存し、測定の行を台帳に足す
4. 作業者が波形を見て判断し、**手を動かす前に**タッチパネルの操作ボタン(と 2 画面目)を押す。LOGGER が測定中なら止めて xdt を保存し、測定の行を足してから、操作の行を足す
5. 作業者が操作(ハンマーで叩く、着減磁する、スペーサーを替える)し、3 に戻る
6. 盲栓確認が OK になったら完了ボタン。アプリは完了の行を足す
7. カバーを付けた測定で NG なら、そのまま操作ボタンを押せば同じ個体の続きとして記録される(完了の取消は自動)

## 異常時

- タッチパネルが見つからない(学習モード): 接続確認の失敗理由に出し、READY LED は点けずスイッチも受け付けない(学習モードは動かない)。通常モードに切り替えれば今までどおり使える
- タッチパネルの通信が途切れた(学習モード): Arduino と同じ作り(250ms ごとの定期応答が 1 秒止まったら操作禁止、3 秒止まる・切断で 2 秒おきに再接続、復旧後 1 秒は操作を捨てる)。途切れている間は READY LED を消し、操作ボタンと PC_go / CR_go / F8 を受け付けない(新しい測定を始めない。記録漏れを作らないため)。sw4 の停止だけは受け付け、xdt の保存と測定の行は残す。測定中の LOGGER と WF1973 の出力は止めない(Arduino の切断と同じ)。復旧したら画面のログに出し、READY LED を戻す
- 決まった雛形が `雛形\` に無い、2 つ以上ある、LOGGER で開けない(学習モード、2026-11-10): ログに理由を出し、雛形待ちのまま(READY LED は点かない)。ドロップすれば使える。接続確認そのものは失敗にしない
- 台帳や xdt に書けない(保存先を作れない、ほかで開かれている): ログと最前面のメッセージボックス(「再試行」ボタン付き)。**保存できるまで止める**: READY LED を消し、PC_go / CR_go / F8 を受け付けず、操作ボタンには `NAK` を返す(台帳に書けないため)。sw4 は受け付ける(止めるものがあれば止める)。保存先を直して「再試行」を押すと、書けなかったものを書き直す(xdt は LOGGER に残っている停止後の波形を `SaveXdt` し直す。次の測定を始めるまで残っている前提で、実機で確かめる)。書けたら READY LED を戻して再開。保存先を直せないときはアプリを終了し、通常モードで起動し直す(記録なしで作業を続ける)
- 測定の行がないのに操作ボタンが押された(測定せずに操作した、起動直後など): そのまま操作の行を足し、備考に「直前の測定なし」と書く。止めない
- 取消ボタンを、取り消せる操作がないときに押した: 何もせずログに出す
- 完了ボタンを続けて 2 回押した: 2 回目は何もせずログに出す

## タッチパネルとのやり取り(案)

Arduino と同じ、行単位のテキスト(115200bps、LF)。文字列はこの追加仕様の専用のものにし、Arduino の文字列とぶつけない(接続確認が COM ポートを総当たりで探すため)。

| 向き | 文字列(案) | 意味 |
|---|---|---|
| PC → パネル | `AS100201_PANEL_PING` | 接続確認 |
| パネル → PC | `AS100201_PANEL_READY:1` | 確認応答(版 1) |
| パネル → PC | `ACT:MAG` | 着磁 |
| パネル → PC | `ACT:DEMAG:FULL` / `ACT:DEMAG:TAP` | 減磁(しっかり / ちょんちょん) |
| パネル → PC | `ACT:NOZZLE:P:IN:2` など | ノズル(P / R、IN=押し込む / OUT=外に出す、1=微調整 / 2=普通 / 3=大きく) |
| パネル → PC | `ACT:SPACER:P:UP` など | スペーサー(P / R、UP=上げる / DOWN=下げる。厚さはいずれ決める) |
| パネル → PC | `DONE` | 完了 |
| パネル → PC | `UNDO` | 取消(パネル側で確認「はい」を押したあとに送る) |
| PC → パネル | `ACK:<受け取った文字列>` | 記録できた(パネルは短く表示) |
| PC → パネル | `NAK:<理由>` | 記録できなかった |
| PC → パネル | `STATE:...` | 表示用(何を出すかは「いずれ決める」の表示内容で決める) |
| パネル → PC | `DIAG_FRAME:<連番>:<millis>` | 定期応答(250ms ごと。Arduino と同じ作り) |
| パネル → PC | `DIAG_BOOT:1` | 起動通知(ポートを開いたときのリセットの検知にも使う) |

- 2 画面目の選択と取消の確認はパネルの中で完結させ、確定した 1 行だけを PC に送る(途中の画面遷移は送らない)
- Tab5(ESP32-P4)の USB-C のシリアルは、PC がポートを開いたときにボードがリセットされる場合がある(`ArduinoConnection` は 1.7 秒待ってから確認文字列を送る)。実機で確かめる
