# specs/

仕様インタビュー(AGENTS.md「仕様決め」)で決まった内容を `specs/<アプリ>/SPEC.md` に置く。承認されるまで実装しない。

## SPEC.md の雛形

```markdown
# <アプリ名> 仕様(<日付>)

## 目的
何のための試験・操作か。合否や結果を誰がどう使うか。

## 使う機器
| 機器 | 役割 | 接続 | 使う wrapper |
|---|---|---|---|

## 入力
人が入力するもの(SN、設定値、保存先、雛形)。可変にするもの・固定値にするもの。

## 出力
ファイル(xdt / Excel)、画面表示、ログ。既存ブックへの追記の要否。

## 手順
開始から終了までの流れ。待ち時間・判定の順番。

## 異常時
機器が見つからない / 通信が切れた / 値が範囲外 / 人が LOGGER を触った、それぞれでどうするか。

## 細部
しきい値、丸め、チャンネル割り当て、文言。

## 未確定・未確認
```
