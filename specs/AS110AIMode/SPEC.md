## 目的(人の依頼、2026-11-12)

AS100201 で進めている、熟練作業者の経験則を学習させ、誰でも製品の微調整ができるようにする。対象の製品は AS110(1 回目の相談)。

理想の運用(人の説明、2 回目の相談): 今の AS110AllCheck の**データ調整モードのときに「次はこうしなさい」という表示を出し、作業者がそれを見て作業する**。データ取りのときも同じく表示させるつもり。表示は、タブレットなど PC とは別にするかもしれない(未定)。

### 操作の一覧(人の回答、2026-11-12。細部はこれから詰める)

| 番号 | 操作 | 細分 |
|---|---|---|
| ① | スペーサーの変更 P 側 | 厚くする / 薄くする。さらに何 μm 変えるか |
| ② | スペーサーの変更 R 側 | 同上 |
| ③ | フル着磁 | 一択(選択肢なし) |
| ④ | 減磁 | 大きく減磁 / 小さく減磁 |
| ⑤ | P 側のボルトを締める | 1 つ / 2 つ |
| ⑥ | R 側のボルトを締める | 同上 |

- AS100-201 との違い: ノズル(P / R)が無く、ボルトを締める(P / R)がある。スペーサーは AS100-201 では厚さを「いずれ決める」としていたが、AS110 では厚くする / 薄くすると μm を入れる

## 未定(人の判断待ち)

### 記録と助言の置き場(人: 「すごく迷っている」)

理想の運用は、AS110AllCheck のデータ調整(とデータ取り)で助言が出ること。測定は AS110AllCheck が行う。

| 選択肢 | 選んだ結果 |
|---|---|
| **AI の提案**: 測定と記録は AS110AllCheck、学習と判断は AS110AIMode | AS110AllCheck に「学習モード」を足して記録を残す(AS100-201 と同じやり方。通常の動きは変えない)。AS110AIMode は記録を読んで学習・分析するアプリとして作り、「次にする操作」を決める部分は部品にしておく。助言の段階では、AS110AllCheck がその部品を呼んで表示する。作業者は今のアプリのまま使え、表示先(PC の画面・タブレット)を後から選べる。AS110AllCheck の発行し直しと実機確認が要る。AS110AllCheck は別のフォルダー(`PSC_AS110AllCheck`)で作業が進んでいるので、変更がぶつからないよう順番を決める |
| AS110AIMode で測定も記録もする | 現場で使用中のデータ調整アプリに手を入れない。記録を取る調整・助言を受ける調整のときは AS110AIMode を使う(2 つ同時には LOGGER を使えない)。測定・Excel 判定の処理を新アプリにも持たせるので作る量が増え、AS110AllCheck を直すたびに同じ直しが要る。理想の運用(AS110AllCheck に表示)とは別の形になる |

### そのほか

- タッチパネルの機種(M5Stack Tab5 と同じにするか)と、助言の表示先(PC の画面 / タッチパネル / 別のタブレット)。入力のパネルと助言の表示を 1 台にまとめるかも決める
- 操作の細部: スペーサーの μm の入れ方(在庫の厚さから選ぶ / 数値 / 段階)、ボルトの「1 つ / 2 つ」の意味(締めるボルトの本数か、締める度合いか)、ボルトを緩める操作があるか、減磁の大小の境目
- 個体の区切り: データ調整は S/N が無い。完了ボタンで区切るか、Excel 転送の合格で区切るか、S/N を入れるか
- 型式(AS110-006・015・035・116B・135B)ごとに学習を分けるか、まとめるか
- 記録に残す測定: LOGGER の波形(xdt)だけか、Excel 転送の判定値(10mA・15mA・20mA の圧力、最大値、立ち上がり)も残すか。合否は「完成までの遠さ」に使える
- NR-X(ydt)での記録を対象にするか(ydt の解析はまだ)
- データ取りでの助言(人: 「同じく表示させるかな」)の範囲
- 記録の保存先(exe の隣か、共有フォルダーか)と、AS110AIMode に読ませる方法

## 段階(AI の提案。置き場が決まったら見直す)

1. **記録**: AS110 の調整を「測定 → 操作 → 測定」で残す仕組みを作る(タッチパネルで操作を入力)
2. **学習・分析**(機器なし): AS110AIMode が記録を読み、三つ組を組み立て、「この波形のとき熟練者は何をしたか」を学ぶ。記録が貯まるまでは模擬の記録で動きを確かめる。過去の出荷データ(結果だけ)は「合格した波形の形」を知るのに使える
3. **助言**: 測定のたびに「次にする操作」を表示する。当たり具合は、熟練者の実際の操作と比べて確かめてから作業者に出す
