### 操作の一覧(人の回答、2026-11-12)

| 番号 | 操作 | 細分 |
|---|---|---|
| ① | スペーサーの変更 P 側 | 厚くする / 薄くする → 狙いの μm → 狙いからのずれ(狙いどおり / +1 / +2 / -1 / -2 μm) |
| ② | スペーサーの変更 R 側 | 同上 |
| ③ | フル着磁 | 一択(選択肢なし) |
| ④ | 減磁 | 大きく減磁 / 小さく減磁 |
| ⑤ | P 側のボルトを締める | 1 本 / 2 本 |
| ⑥ | R 側のボルトを締める | 同上 |

- AS100-201 との違い: ノズル(P / R)が無く、ボルトを締める(P / R)がある。スペーサーは AS100-201 では厚さを「いずれ決める」としていたが、AS110 では向きと μm を入れる
- 狙いの μm は、在庫の厚さから選ぶ形でも、数値で入れる形でもよい(人)。画面の作りは未定

### タブレットのボタン(決めたことのまとめ)

| ボタン | 押したあと |
|---|---|
| スペーサー P 側 / R 側 | 厚くする / 薄くする → 狙いの μm → 狙いからのずれ |
| フル着磁 | すぐ確定 |
| 減磁 | 大きく / 小さく |
| ボルトを締める P 側 / R 側 | 1 本 / 2 本 |
| 中止 | この製品の調整を途中でやめた |
| 不良 | この製品は調整しきれなかった |

### 完了の印(5 回目に人が承認、6 回目にボタンを 2 つに分けた)

人の質問「完了ボタンと Excel 転送の合格を融合できないか」への答え。

1. **Excel 転送(B)で合格が出たら、アプリが自動で「完了(合格)」の行を台帳に足す**。作業者は何も押さない。タブレットには「合格・完了を記録」と短く出す
2. **合格を出さずに終えるとき**は、タブレットの「中止」か「不良」を押す。台帳には「完了(中止)」「完了(不良)」の行になり、合格で終わった個体と区別できる
3. 合格のあとに操作ボタンが押されたら、**前の完了は取消、同じ個体の続き**として扱う(AS100-201 と同じ。合格後にもう少し追い込む場合)
4. 合格のあと、操作ボタンを押さずに次の測定が始まったら、次の個体の始まりとして扱う

- ふだんは合格が区切りになるので押し忘れが起きない。「中止」「不良」は例外のときだけ使う

### 段階

1. **記録**: AS110AllCheck に学習モードを足し、調整を「測定 → 操作 → 測定」で残す(タブレットで操作を入力)
2. **学習・分析**(機器なし): AS110AIMode が記録を読み、型式ごとに三つ組を組み立て、「この波形のとき熟練者は何をしたか」を学ぶ。記録が貯まるまでは模擬の記録で動きを確かめる。過去の出荷データ(結果だけ)は「合格した波形の形」を知るのに使える
3. **助言**: 測定のたびに「次にする操作」を表示する。当たり具合は、熟練者の実際の操作と比べて確かめてから作業者に出す

- 段階 1 は AS110AllCheck の変更。AS110AllCheck は別のフォルダー(`PSC_AS110AllCheck`)で作業が進んでいるので、どちらのフォルダーで作業するかと順番を決めてから始める
- 段階 2 は段階 1 の記録の形(台帳の列)が決まれば、並行して作れる

### 記録に残すもの

- 測定のたびに LOGGER の波形(xdt)を保存する(今のデータ調整は保存しない)
- Excel 転送をしたときは、判定値(10mA・15mA・20mA の圧力、圧力最大値、立ち上がり、E21・L21 の合否)も台帳に残す。「完成までの遠さ」を数字にできる
- 型式(参照波形から決まる)を測定の行に残す(学習を型式ごとに分けるため)
- 台帳の形は AS100-201 と同じ CSV(1 行 1 出来事、追記のみ)
