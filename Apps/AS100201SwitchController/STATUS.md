## 今の状態

- 通常モード(スイッチで位相の出し直しと LOGGER の開始・停止): 移植・実機確認済み。2 回押しと位相の入力は実装済みで、実機は未確認
- 学習モード(調整操作の記録): PC 側は実装済み。測定中の取り込みも実装済み(NR-500・旧 WAVE LOGGER で一部を実機確認)
- タッチパネル(M5Stack Tab5): 版 1 のスケッチで、USB での接続確認は実機で通った(2026-11-13、Tab5 = COM8、Arduino = COM4)
- Tab5 の Wi-Fi・バッテリー(版 2)と、人の指示の修正(版 3: ノズルは方向だけ〈近づける / 離す〉、スペーサーの厚さと表示との差のページ、パネルに触れたら測定を止める `HOLD`)を 2026-11-13 に実装。アプリの最前面固定もやめた(AS110AllCheck と同じ)。ビルド・模擬テスト・スケッチのコンパイルまで。**実機は未確認**(Tab5 に版 3 を書き込むまで、学習モードは版違いで接続エラーになる)

## 次にやること

1. Tab5 に版 3 のスケッチを書き込み、USB での接続確認と、スペーサーの厚さ・差のページの見え方を確かめる(レイアウトは人が変える前提)
2. 測定中にパネルに触れて LOGGER が止まり、測定の行と xdt が残るかを確かめる(1 画面目のボタン・暗い画面)
3. 子機とバッテリーが届いたら、README「Tab5 を Wi-Fi・電池で使う」の準備をして、Wi-Fi・切り替え・電池残量・画面を暗くするを実機で確かめる
4. 学習モードの実機の通し確認(操作 → 台帳 → xdt)と、実際の調整作業で 1 個体ぶんの記録

## 詰まっている点・待っているもの

- バッテリー(NP-F550 互換)と PC 用の USB Wi-Fi 子機(2.4GHz)の用意
- Tab5 の Wi-Fi が esp32 3.3.12 で動くか(動かなければ USB で使い続けられる)
- スペーサーの箱の札(手書き)の読み違いがないか、人が一覧を確かめる(0.271・0.398・0.427・0.568 など)
- PC / CR の区間分け(測定中の取り込み)は相談中・未承認
- 発振器が見つからないと、接続確認で約 2 分画面が止まる(以前からの動き。直すかは未定)

## 決めたこと(直近)

- 版 3(人の指示): ノズルの程度をやめ方向だけ。スペーサーは 上げる / 下げる → 厚さ(箱の表示 49 種、3 タブ)→ 表示との差(-3〜+3μm・測っていない)。パネルに触れた時点で測定を止める
- 台帳: 厚さは「厚さ」の列、差は「程度」の列(`差+2μm`。列を増やさないための仮決め)
- 準備中もアプリを最前面に固定しない(一度だけ前に出す)
