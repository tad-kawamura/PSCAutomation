## 今の状態

- 通常モード(スイッチで位相の出し直しと LOGGER の開始・停止): 移植・実機確認済み。2 回押しと位相の入力は実装済みで、実機は未確認
- 学習モード(調整操作の記録): PC 側は実装済み。測定中の取り込みも実装済み(NR-500・旧 WAVE LOGGER で一部を実機確認)
- タッチパネル(M5Stack Tab5): 版 1 のスケッチで、USB での接続確認は実機で通った(2026-11-13、Tab5 = COM8、Arduino = COM4)
- Tab5 の Wi-Fi・バッテリー: 2026-11-13 に承認され、実装した(共通部品 `TcpLineConnection`、USB と Wi-Fi の 2 本、電池残量、画面を暗くする、スケッチ版 2)。ビルドと模擬テストまで。**実機は未確認**(Tab5 に版 2 を書き込むまで、学習モードは版違いで接続エラーになる)

## 次にやること

1. Tab5 に版 2 のスケッチを書き込み、USB での接続確認が今までどおり通るかを見る
2. 子機とバッテリーが届いたら、README「Tab5 を Wi-Fi・電池で使う」の準備をして、Wi-Fi での接続・USB ⇔ Wi-Fi の切り替え・電池残量・画面を暗くするを実機で確かめる(PC のふだんのネットワークが使えたままかも)
3. Tab5 の実物を見て、画面のレイアウトと表示内容(`STATE:`)を決める
4. 学習モードの実機の通し確認(操作 → 台帳 → xdt)と、実際の調整作業で 1 個体ぶんの記録

## 詰まっている点・待っているもの

- バッテリー(NP-F550 互換)と PC 用の USB Wi-Fi 子機(2.4GHz)の用意
- Tab5 の Wi-Fi が esp32 3.3.12 で動くか(動かない報告のある版がある。動かなければ USB で使い続けられる)
- PC / CR の区間分け(測定中の取り込み)は相談中・未承認
- 発振器が見つからないと、接続確認で約 2 分画面が止まる(以前からの動き。直すかは未定)

## 決めたこと(直近)

- Tab5 を Wi-Fi の親機にし、PC は専用の USB Wi-Fi 子機でつなぎっぱなし。USB も残し、両方なら USB、切れたらもう一方へ自動で移る
- 見張りの秒数は今と同じ。Tab5 の IP・ポートはアプリの設定(`As100201PanelNetworkSettings`)、Wi-Fi の名前・パスワードはスケッチ
- 電池残量を Tab5 に出し、20% 以下で PC のログに 1 回。60 秒触らなければ画面を暗くし、暗いときの最初のタッチは受け付けない
