# AS100201SwitchController

AS100-201 のスイッチ制御・測定アプリ。タッチパネル(M5Stack Tab5)のボタンを受け取り、WF1973 の連続出力(三角波)を位相をそろえて出し直し、KEYENCE WAVE LOGGER の測定開始・停止を行う。**版 6(2026-11-27 人の承認・実装)で Arduino のスイッチ箱をやめ、通常モードでも Tab5 を使う**(それまでは治具の Arduino のスイッチ PC_go / CR_go / F8 / sw4)。

元は GitHub `tad-kawamura/AS100201SwitchController`(`5eb5b6391a82`、2026-10-28)。旧リポジトリは 2026-11-04 にアーカイブした(読み取り専用)。移植前の履歴はそちらで見る。旧リポジトリの README・AGENTS.md の冒頭には、ここへの案内を書いてある(`c8a5e4b`)。旧リポジトリをクローンした PC は、PSCAutomation をクローンし直して作業する。

- 仕様(機器・操作・異常時・移植で変えたこと): [specs/AS100201SwitchController/SPEC.md](../../specs/AS100201SwitchController/SPEC.md)
- Arduino スケッチ: `firmware/ArduinoSwitchAndReadyLed/ArduinoSwitchAndReadyLed.ino`。**版 6 からアプリは使わない**(Arduino を探さない。スケッチと取り決めの部品 `As100201ArduinoProtocol` は消さずに残してある)。版 2(2026-11-09、PC_go / CR_go の 2 回押しの判定を追加)。書き込みは Arduino IDE で(ボードは UNO R4 Minima)
- タッチパネルのスケッチ: `firmware/Tab5LearningPanel/Tab5LearningPanel.ino`。**版 6**(2026-11-27。1 画面目に発振器の 4 つと「バルブを動かす」・完了・取消、操作の画面、ノズルの立ち上がりを合わせる画面、通常モードの画面。アプリも版 6 で、版 5 までのスケッチは接続エラー。下の「版 6」)。それまでは**版 5**(2026-11-26。1 画面目の右の列に「測定中に動かした」の印を足し、取消の確認に PC から届く直前の記録(`LAST:`)を出す。アプリも版 5 で、版 4 までのスケッチは接続エラー)。それまでは**版 4**(2026-11-13、横置き・仮レイアウト。版 4 で選び終わるまで測定できない `SELECT` / `HOME` を足した。版 2 で USB と Wi-Fi・電池・画面を暗くする、版 3 でノズルを方向だけに・スペーサーの厚さと差のページ・触れたら測定を止める `HOLD` を足した)。2026-11-17 に、起動時に無線用チップの電源を入れ直す処理と診断の行 `DIAG_WIFI:` を足した(版は 4 のまま)。2026-11-19 にスペーサーの厚さのページの題名をなくし、5 列のボタンを高くした(7 列も試したが数字が窮屈だった。画面だけの変更で版は 4 のまま。arduino-cli でのコンパイルと、Tab5 に書き込んで人が見て OK)。同じ日に、PC の子機がいきなり抜けたときに Tab5 が気づくようにした(下の「Tab5 を Wi-Fi・電池で使う」。版は 4 のまま。子機を抜くと「切れました」が出ることを実機で確認)。書き込みは下の「タッチパネルのスケッチを書き込む」、Wi-Fi の準備は「Tab5 を Wi-Fi・電池で使う」

## 開く・ビルドする

Visual Studio ではリポジトリのルートの `AS100201SwitchController.slnf` を開く(アプリ・互換テスト・使う wrapper 5 つ)。

```powershell
dotnet build AS100201SwitchController.slnf
```

NI-VISA が入っていない PC ではビルドできない(`Wrappers/Instruments` が `Ivi.Visa.Interop` を参照するため)。

## 操作

| 操作 | 動作 |
|---|---|
| 起動 | まず「通常モード / 学習モード」を選ぶ窓が出る(初期選択は通常。× も通常)。次に WF1973・LOGGER/NR 本体(USB)とタッチパネル(Tab5、USB か Wi-Fi)を確認する(版 6 から通常モードでも Tab5 が要る。Arduino は探さない)。WF1973 は三角波にする。「確認」ボタンでやり直せる |
| 「確認」(WF1973 が接続済み) | WF1973 の生存確認のあと、波形の形(三角波)だけを送り直す。出力・振幅・位相は変えない(形が DC などになっていたら、これで戻る) |
| 雛形を画面へドロップ | LOGGER で開く。測定の準備ができる(学習モードは接続確認のあとに決まった雛形を自動で開くので、ふだんはドロップしない) |
| Tab5 の PC / CR(PC 位相1・2、CR 位相1・2) | WF1973 をその位相(初期 PC 0° / 75°、CR 140° / 250°)で出し直し、止まっていれば**そのまま測り始める**(版 6。「測定開始」のボタンは置かない)。測っている間に押すと、通常モードは位相だけ切り替えて測り続ける。学習モードは下の「版 6」 |
| Tab5 の「測定停止」(通常モード) | LOGGER の停止 |
| 画面の「出し直しの位相」 | 4 つの位相(0〜359°)を入力する。次の押下から効き、Tab5 のボタンの名前(「PC 75°」など)にも出る。exe の隣の `AS100201SwitchController.settings.json` に残す(書けなければ `%LOCALAPPDATA%\AS100201SwitchController\`。項目名は 2 回押しのころのまま)。「初期値に戻す」あり |
| 「測定開始（確認用）」 | LOGGER の測定開始(毎回 Start。WF1973 は変えない) |
| 「測定停止」(PC の画面、版 6) | LOGGER の停止。いつも押せる(Tab5 が切れたとき・パネルの処理中も)。学習モードなら測定の行と xdt を残す |

NR 本体は **USB だけ**(NR-500 / NR-X)。移植前にあった Wi-Fi の選択と「元のWi-Fiへ戻す」ボタンは外した(SPEC.md)。

## 学習モード(2026-11-09 承認、PC 側は実装済み、実機は一部確認)

仕様は [SPEC_調整操作の記録.md](../../specs/AS100201SwitchController/SPEC_調整操作の記録.md)。熟練者の流量調整を「操作前の測定 → 操作 → 操作後の測定」の三つ組で貯め、ゆくゆく AI に判断を学習させるためのもの。**通常モードの動きは変えていない**(通常モードでは学習モードの部品を作らない)。

### 使い方(学習モード)

1. 起動の窓で「学習モード」を選ぶ(Tab5 なしで試すときは引数 `--virtual-panel` で起動する。下の「Tab5 なしで確かめる」)。タイトルと画面上部に「学習モード」と出る。接続確認に**タッチパネル(M5Stack Tab5、USB または Wi-Fi。2026-11-13 から)**が加わり、見つからなければ測定できない(版 6 からは通常モードでも同じ)
2. 接続確認が通ると、exe の隣の `雛形\` にある xdt(`雛形_AS100_201流量調整用_650kPa_0_02Hz_10Vpp.xdt`)を自動で LOGGER に開く(**ドロップ不要**、2026-11-10 人の決定)。`雛形\` に xdt が無い・2 つ以上ある・開けないときは、ログに理由を出して雛形待ちのまま(ドロップすれば使える)。別の雛形を使うときは「雛形を削除」してからドロップする(保存先は変わらない)。「確認」を押し直すと、決まった雛形を開き直す。**続けて、同じ `雛形` にある参照波形(`参照ﾃﾞｰﾀ_AS100-201_盲栓PC+CR_SN149.xyb`、PC と CR を 1 本につないだもの)を自動で 1 回読み込む**(2026-11-26 人の決定。LOGGER のファイル選択の窓が一瞬見える)。PC_go / CR_go で切り替えない(両方いつも出る)。.xyb が無い・2 つ以上・読み込めないときは READY LED を消して測定を受け付けず、「次にすること」に直し方が出る(置き直して「確認」)。通常モードは読み込まない
3. **個体のシリアル番号を、画面の「シリアル番号」に数字で入れて「決定」(Enter でもよい)**(2026-11-26 人の決定。`SN` は自動で付き 3 桁にそろう: `145` → `SN145`)。起動した直後と「完了」のあとは番号が空で、入れるまで Tab5 の PC / CR とパネルの操作・完了・取消を受け付けない(パネルには `NAK:シリアル番号を入れてください`。PC の画面の「測定停止」は受け付ける)。台帳にもうある番号を入れると「続きとして記録しますか」と聞く(はい: 台帳から回数と完了かどうかを数え直して続き。完了済みなら次の操作で「完了の取消」。いいえ: 入れ直し)。完了せずに別の番号を入れたら、そのまま切り替えて番号の行の備考とログに残す。測定中・パネルで選んでいる途中・保存の停止中は番号を変えられない
4. 作業者は Tab5 の 1 画面目の PC / CR を押して波形を見る(版 6。押すと位相を出し直して測り始める)。止まるたびに(下の「版 6」)、アプリが測定の行を台帳に足し、LOGGER の状態が停止に戻った時点で xdt を保存する(名前は `yyyyMMdd_HHmmss_SN145_PC.xdt`。位相2 の側は `PC2` / `CR2`(台帳の「側」は `PC（位相2）`。版 5 までは `PC（2回押し）`)、位相を出し直していなければ側なし、同じ秒は `_2`。2026-11-09 人の決定、番号は 2026-11-26 から)

**保存先(2026-11-10 人の決定。番号のフォルダーは 2026-11-26 から、それまでは日付フォルダー)**: exe の隣の `学習データ\`。台帳 `調整記録.csv` はその直下に 1 つ、xdt と取り込みの CSV はシリアル番号のフォルダーに置く(1 個体が日をまたいでも、やり直しても 1 か所)。フォルダーは最初に書くときにアプリが作る。番号が無いまま LOGGER が止まったとき(ふだんは起きない)は `番号なし\` に置く。

```
exe の隣\学習データ\
  調整記録.csv                  ← 台帳は 1 つ(「ファイル」列は SN145\20261126_101530_SN145_PC.xdt のように番号のフォルダー付き)
  SN145\
    20261126_101530_SN145_PC.xdt
    20261126_101530_SN145_PC.csv  ← 測定中の取り込み
```

**番号の列を足す前の台帳**(列が 1 つ少ない。試しのデータ)が `学習データ\` にあると、起動時に「台帳の列の形が今の作りと違います」と出して止まる(形の違う行を混ぜないため)。台帳を消すか別の場所へ移してから「再試行」を押す。
5. 手を動かす前に Tab5 の「バルブを動かす」を押す。**測定中ならここで LOGGER を止めて測定の行を書き**(停止のきっかけ「バルブを動かす」)、操作の画面(着磁・減磁・ノズル P/R・スペーサー P/R)へ移る。減磁は程度、スペーサーは向き → 厚さ → 表示との差で確定すると操作の行を足す。ノズルは下の「版 6」。パネルには `ACK:<行>` / `NAK:<理由>` を返す。**操作を選んでいる途中は測定を始められない**(版 4)。確定するか「戻る」で 1 画面目に戻ると始められる。**「バルブを動かす」を押す前に測定したまま手を動かしてしまったときは、操作の画面の「測定中に動かした」を入れてから操作を選ぶ**(版 5。版 6 で操作の画面へ移した。操作の行の備考に「測定中に動かした」と残る。入れたら次の操作 1 件で切れる)
6. 盲栓確認 OK で「完了」。番号が空になるので、次の個体の番号を入れる。カバーを付けて NG で戻ったときは、同じ番号を入れて「はい」で続き(次の操作の備考が「完了の取消」)。「取消」は直前の測定か操作の 1 件だけ(版 5 から測定も。空気の入れ忘れなど失敗した測定を「使わない」にする。測定中に押すと、止めたその測定が対象になる)。完了・番号のあとと、取り消したあとは取り消せない。Tab5 の確認には PC が知らせる対象(「直前の測定（10:15:03 PC）」など)が出る。取消の行は、測定なら「ファイル」列にその xdt(xdt は消さない)、操作なら「操作」などの列に対象を書く。測定なしの操作は備考「直前の測定なし」

台帳は UTF-8(BOM 付き、Excel でそのまま開ける)、新しいファイルの先頭だけヘッダー行、追記のみ。列: 日時、シリアル番号(2026-11-26。全部の行に、その時点の番号)、種類、側、位相、停止のきっかけ、操作、方向、程度、厚さ(スペーサーの箱の表示 mm。版 3)、ファイル、備考。種類は 測定 / 操作 / 完了 / 取消 / 押した / 番号。番号の行(番号を決めたとき)の備考は「新規」「続き（完了済み）」「続き（未完了）」で、前の番号が完了していなければ「前の番号 SN144 は完了せず切り替え」を足す(起動し直したことも、この行で分かる)。 スペーサーの表示との差は「程度」の列に `差+2μm` / `差0μm` / `差未測定` と書く(版 3、列を増やさないための仮決め)。ノズルの「程度」は空(版 2 までは微調整 / 普通 / 大きく)。

### Tab5 を Wi-Fi・電池で使う(版 2、2026-11-13 承認・実装。接続と USB からの切り替えは 2026-11-17 に実機で確認)

SPEC_調整操作の記録.md「Wi-Fi・バッテリーへの変更」。Tab5 が Wi-Fi の親機になり、PC は **Tab5 専用の USB Wi-Fi 子機**でつなぎっぱなしにする(アプリは接続先を切り替えない。つながらないときに子機を同じ登録でつなぎ直すだけ(2026-11-17)。PC のふだんの Wi-Fi・有線はそのまま)。USB ケーブルでもつながり、両方つながっていれば USB を使う。

最初に 1 回だけ、PC で準備する:

1. USB Wi-Fi 子機(2.4GHz 対応・Windows 11 対応)を挿す。Windows の「設定 → ネットワークとインターネット」に Wi-Fi が 2 つ(内蔵と子機、例「Wi-Fi」「Wi-Fi 2」)出る
2. Tab5 に版 2 のスケッチを書き込んで起動する。下の帯に「USB か Wi-Fi(AS100201_PANEL)でつながります」と出る(「Wi-Fi を始められませんでした」なら Wi-Fi は使えない。USB では使える)
3. タスクバーの Wi-Fi の一覧で、**子機の方**を選んで `AS100201_PANEL` に接続する。パスワードはスケッチの `WIFI_PASSWORD`。「自動的に接続」に印を付ける(Windows の Wi-Fi の登録はアダプターごとなので、内蔵の方で登録しても子機には効かない)
4. 内蔵の Wi-Fi が `AS100201_PANEL` に、子機が社内 Wi-Fi に自動でつながらないようにする(内蔵の方で `AS100201_PANEL` を登録しない。子機の方で社内 Wi-Fi の「自動的に接続」を外す)。**内蔵の方に `AS100201_PANEL` の登録があると、アプリは内蔵まで切らないよう子機のつなぎ直しをしない**(ログに理由が出る)。この PC(Windows 11)では、社内 Wi-Fi の登録が子機と内蔵で共通に見え、「自動的に接続」の設定も両方で同じになっていた(2026-11-17)。子機の方で外したあと、内蔵が社内 Wi-Fi に自動でつながるかを確かめる
5. 子機が `AS100201_PANEL` につながったまま、社内のネットワーク・インターネットがふだんどおり使えることを確かめる(Tab5 はゲートウェイを渡さないので、子機の側は「インターネットなし」と出るのが正しい)。PC の IP は Tab5 から 192.168.4.2〜 が配られる。社内 LAN が 192.168.4.x なら、スケッチの `PANEL_IP` とアプリの `As100201/As100201PanelNetworkSettings.cs` を両方変える

PC は Tab5 の 192.168.4.1:50201 へ TCP でつなぎに行く(PC は待ち受けないので、ファイアウォールの設定は要らない)。

## 測定中の取り込み(学習モード、2026-11-11 承認・実装、アプリでの実機は一部確認)

仕様は [SPEC_測定中の取り込み.md](../../specs/AS100201SwitchController/SPEC_測定中の取り込み.md)。ゆくゆく AI が測定中に「今どの操作をするのが完成に最も近づくか」を出すための下地で、**今は取り込んで加工し、CSV に残すだけ**(助言は出さない。画面にも値を出さない)。通常モードは何も変えていない。

- 雛形を LOGGER で開く前に、雛形の xdt からチャンネルと換算係数を読む(ログに「測定中の取り込み：雛形のチャンネル …」)。読めない雛形では F8 を受け付けない

## 確認(2026-11-04、移植後)

実機: WF1973(USB)・NR-500(USB、旧 WAVE LOGGER)・Arduino UNO R4 Minima(COM4、同梱スケッチ)。PC には WAVE LOGGER X も入っている。Debug ビルドの exe で、人がスイッチを押し、アプリのログ・異常ログと人の目視で確かめた。

| 項目 | 結果 |
|---|---|
| 起動時の接続確認 | 3 機器とも成功(約 1.8 秒)。LOGGER は旧 WAVE LOGGER、本体は NR-500 |
| 雛形のドロップ | 測定済みの AS100-201 の xdt(流量 PC)で成功。READY LED 点灯(目視) |
| PC_go / CR_go | 位相 15° / 165° で出し直し(1 回目約 90ms、以後 3〜5ms)。**三角波で位相が切り替わり、出力は途中で OFF にならない**(目視)。約 0.45 秒間隔の PC→CR の連続押下も両方とも処理 |
| F8 → sw4 | 3 回とも開始・停止。停止後すぐの F8 でも開始できた(目視でも確認) |
| Arduino の USB 抜き差し | 2 回とも自動で再接続(COM ポートが戻ってから約 1.7 秒。起動待ちの分)。抜いている間は READY LED 消灯、再接続後に再点灯(目視)。抜き差しだけでは WF1973・LOGGER は動かない(ログと目視)。2 回目は測定中に抜いたが、LOGGER へ停止を送らなかった(ログ) |
| 再接続後の操作 | PC_go・CR_go・F8・sw4 が通常どおり動く |
| 接続済みでの「確認」で形を戻す | アプリが WF1973 を開いたまま、別の通信(作業用の確認プログラム。WF1973 は接続中リモートになり前面パネルでは変えられないため)で形を DC にし、「確認」を押した。形は RAMP・対称 50% に戻り、出力は OFF のまま変わらなかった(読み出しで確認)。「確認」の WF1973 の部分は約 0.17 秒 |
