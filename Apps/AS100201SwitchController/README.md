# AS100201SwitchController

AS100-201 のスイッチ制御・測定アプリ。治具の Arduino のスイッチ操作を受け取り、WF1973 の連続出力(三角波)を位相をそろえて出し直し、KEYENCE WAVE LOGGER の測定開始・停止を行う。

元は GitHub `tad-kawamura/AS100201SwitchController`(`5eb5b6391a82`、2026-10-28)。旧リポジトリは 2026-11-04 にアーカイブした(読み取り専用)。移植前の履歴はそちらで見る。旧リポジトリの README・AGENTS.md の冒頭には、ここへの案内を書いてある(`c8a5e4b`)。旧リポジトリをクローンした PC は、PSCAutomation をクローンし直して作業する。

- 仕様(機器・操作・異常時・移植で変えたこと): [specs/AS100201SwitchController/SPEC.md](../../specs/AS100201SwitchController/SPEC.md)
- Arduino スケッチ: `firmware/ArduinoSwitchAndReadyLed/ArduinoSwitchAndReadyLed.ino`。**版 2**(2026-11-09、PC_go / CR_go の 2 回押しの判定を追加)。**アプリとスケッチは一緒に更新する**: 版 1 のスケッチをこのアプリにつなぐと接続エラー(「スケッチが古い」)、版 2 のスケッチを 2026-11-09 より前のアプリにつなぐと「Arduino が見つからない」になる。書き込みは Arduino IDE で(ボードは UNO R4 Minima)

## 開く・ビルドする

Visual Studio ではリポジトリのルートの `AS100201SwitchController.slnf` を開く(アプリ・互換テスト・使う wrapper 4 つ)。

```powershell
dotnet build AS100201SwitchController.slnf
```

NI-VISA が入っていない PC ではビルドできない(`Wrappers/Instruments` が `Ivi.Visa.Interop` を参照するため)。

## 操作

| 操作 | 動作 |
|---|---|
| 起動 | まず「通常モード / 学習モード」を選ぶ窓が出る(初期選択は通常。× も通常)。通常モードを選べば今までどおり。次に Arduino・WF1973・LOGGER/NR 本体(USB)を確認する。WF1973 は三角波にする。「確認」ボタンでやり直せる |
| 「確認」(WF1973 が接続済み) | WF1973 の生存確認のあと、波形の形(三角波)だけを送り直す。出力・振幅・位相は変えない(形が DC などになっていたら、これで戻る) |
| 雛形を画面へドロップ | LOGGER で開く。READY LED が点く |
| PC_go / CR_go(1 回押し) | **離してから待ち時間(初期 0.25 秒)後に**、WF1973 を 1 回押しの位相(初期 PC 0° / CR 140°)で出し直す。出力中は OFF にしない。処理中の再押下は最後の押下で上書き |
| PC_go / CR_go(2 回押し) | 1 回目を離してから待ち時間以内にもう一度押すと、2 回目を押した瞬間に 2 回押しの位相(初期 PC 75° / CR 250°)で出し直す。3 回以上続けて押しても 2 回押し 1 回(続きはログだけ)。待ち中に別のボタンを押すと、待っていた 1 回押しを先に動かす |
| 画面の「出し直しの位相」 | 4 つの位相(0〜359°)と 2 回押しの待ち時間(0.05〜1.00 秒)を入力する。位相の入力は標準の機能(2 回押しは試用中)。次の押下から効く。exe の隣の `AS100201SwitchController.settings.json` に残す(書けなければ `%LOCALAPPDATA%\AS100201SwitchController\`)。「初期値に戻す」あり |
| F8 / 「測定開始（確認用）」 | LOGGER の測定開始(毎回 Start)。2 回押しなし(押した瞬間) |
| sw4 | LOGGER の停止。2 回押しなし(押した瞬間) |

NR 本体は **USB だけ**(NR-500 / NR-X)。移植前にあった Wi-Fi の選択と「元のWi-Fiへ戻す」ボタンは外した(SPEC.md)。

## 学習モード(2026-11-09 承認、PC 側を実装中、実機未確認)

仕様は [SPEC_調整操作の記録.md](../../specs/AS100201SwitchController/SPEC_調整操作の記録.md)。熟練者の流量調整を「操作前の測定 → 操作 → 操作後の測定」の三つ組で貯め、ゆくゆく AI に判断を学習させるためのもの。**通常モードの動きは変えていない**(通常モードでは学習モードの部品を作らない)。

### 使い方(学習モード)

1. 起動の窓で「学習モード」を選ぶ。タイトルと画面上部に「学習モード」と出る。接続確認に**タッチパネル(ESP32-S3、USB シリアル)**が加わり、見つからなければ READY LED は点かずスイッチも受け付けない(通常モードで起動し直せば今までどおり)
2. 保存先フォルダー(xdt と台帳 `調整記録.csv` の置き場)を決める。**決め方は相談中**(画面で選び前回値を残す / 雛形と同じフォルダー / 固定。決まるまで「保存先：未設定」と出て、学習モードでは測定を始められない)
3. 作業者は今までどおり PC_go / CR_go → F8 → sw4 で測定する。sw4 で止まるたびに、アプリが測定の行を台帳に足し、LOGGER の状態が停止に戻った時点で xdt を保存する(仮の名前 `yyyyMMdd_HHmmss_PC.xdt`。2 回押しの側は `PC2` / `CR2`、同じ秒は `_2`)
4. 手を動かす前にタッチパネルの操作ボタン(着磁・減磁・ノズル P/R・スペーサー P/R、2 画面目で方向・程度)を押す。測定中なら LOGGER を止めて測定の行を書いてから、操作の行を足す。パネルには `ACK:<行>` / `NAK:<理由>` を返す
5. 盲栓確認 OK で「完了」。完了のあとに操作が来たら備考「完了の取消」で同じ個体の続き。「取消」は直前の操作 1 件だけ(測定・完了を挟むと取り消せない)。測定なしの操作は備考「直前の測定なし」

台帳は UTF-8(BOM 付き、Excel でそのまま開ける)、新しいファイルの先頭だけヘッダー行、追記のみ。列: 日時、種類、側、位相、停止のきっかけ、操作、方向、程度、厚さ(未使用)、ファイル、備考。

### 異常時(学習モード)

- タッチパネルの定期応答が止まる・切断: Arduino と同じ作り(1 秒で操作禁止、3 秒・切断で 2 秒おきに再接続、復旧後 1 秒は捨てる)。途切れている間は READY LED を消し、PC_go / CR_go / F8 と操作ボタンを受け付けない。**sw4 の停止だけ受け付け**、xdt と測定の行は残す
- 台帳や xdt に書けない: 最前面のメッセージボックス(「再試行」「キャンセル」)。保存できるまで READY LED を消し、PC_go / CR_go / F8 を受け付けず、操作ボタンには `NAK`。測定の行と xdt は覚えておき、「再試行」(メッセージボックス、または画面の「再試行」ボタン)で順に書き直して再開する。操作ボタンは記録されないので、再開後に押し直す

### タッチパネルとのやり取り

Arduino と同じ 115200bps・LF の行単位。PC → `AS100201_PANEL_PING`、パネル → `AS100201_PANEL_READY:1`(版 1 以外は接続エラー)、`DIAG_FRAME:<連番>:<millis>`(250ms)、`DIAG_BOOT:1`、操作は `ACT:MAG` / `ACT:DEMAG:FULL|TAP` / `ACT:NOZZLE:P|R:IN|OUT:1|2|3` / `ACT:SPACER:P|R:UP|DOWN` / `DONE` / `UNDO`。パネルのスケッチ(`firmware/` 配下に新規)は**型番と画面ライブラリが決まってから**作る。スケッチは Arduino 向けの `AS100201_PING` を無視すること(接続確認が COM ポートを総当たりで探すため、Arduino の確認文字列がパネルにも届く。逆に Arduino のスケッチは知らない行を無視する)。

### 確認した範囲と未確認(学習モード)

確かめたのは、ビルド(`AS100201SwitchController.slnf`)、互換テスト 21 グループ(模擬)、機器につながずに描いた画面の画像(モード選択の窓、学習モードの帯と記録の状態、通常モードが今までと同じ見た目)まで。**実機では未確認**:

- タッチパネルの接続確認(Arduino と並べて 2 台の総当たり。Arduino の確認の後にパネルを確認する作りにした。Arduino が外れている間にパネルの確認が Arduino のポートを開いてリセットさせないか)
- ボタンから台帳の行までの通し、`ACK` / `NAK` の表示
- 操作ボタンで測定中の LOGGER を止めたときの xdt(停止直後の状態 10 / 12 を経て 1 に戻ってから `SaveXdt` する作り)。LOGGER が自動で止まったとき(sw4 なし)の行と xdt
- 停止後の波形が次の Start まで LOGGER に残り、「再試行」の `SaveXdt` で保存できること。エラー停止(状態 11)のときの `SaveXdt`
- パネルの USB を抜き差ししたときの再接続(抜いている間に測定を始められず sw4 は効くこと)
- ESP32-S3 のポートを開いたときのリセットの有無(`ArduinoConnection` の 1.7 秒待ちで足りるか)
- 静電容量タッチの反応(素手・作業手袋)
- 「確認」ボタンや「雛形を削除」を測定中に押したとき、その測定は記録されない(LOGGER を止めるだけ)。記録が要るなら決める

## 確認(2026-11-04、移植後)

実機: WF1973(USB)・NR-500(USB、旧 WAVE LOGGER)・Arduino UNO R4 Minima(COM4、同梱スケッチ)。PC には WAVE LOGGER X も入っている。Debug ビルドの exe で、人がスイッチを押し、アプリのログ・異常ログと人の目視で確かめた。

| 項目 | 結果 |
|---|---|
| 起動時の接続確認 | 3 機器とも成功(約 1.8 秒)。LOGGER は旧 WAVE LOGGER、本体は NR-500 |
| 雛形のドロップ | 測定済みの AS100-201 の xdt(流量 PC)で成功。READY LED 点灯(目視) |
| PC_go / CR_go | 位相 15° / 165° で出し直し(1 回目約 90ms、以後 3〜5ms)。**三角波で位相が切り替わり、出力は途中で OFF にならない**(目視)。約 0.45 秒間隔の PC→CR の連続押下も両方とも処理 |
| F8 → sw4 | 3 回とも開始・停止。停止後すぐの F8 でも開始できた(目視でも確認) |
| Arduino の USB 抜き差し | 2 回とも自動で再接続(COM ポートが戻ってから約 1.7 秒。起動待ちの分)。抜いている間は READY LED 消灯、再接続後に再点灯(目視)。抜き差しだけでは WF1973・LOGGER は動かない(ログと目視)。2 回目は測定中に抜いたが、LOGGER へ停止を送らなかった(ログ) |
| 再接続後の操作 | PC_go・CR_go・F8・sw4 が通常どおり動く |
| 接続済みでの「確認」で形を戻す | アプリが WF1973 を開いたまま、別の通信(作業用の確認プログラム。WF1973 は接続中リモートになり前面パネルでは変えられないため)で形を DC にし、「確認」を押した。形は RAMP・対称 50% に戻り、出力は OFF のまま変わらなかった(読み出しで確認)。「確認」の WF1973 の部分は約 0.17 秒 |

**移植の実機確認で見つけて直したこと**: 最初の確認で、PC_go / CR_go を押しても WF1973 が DC のままだった。アプリの送ったコマンド(位相・出力 ON)は正しく、WF1973 本体の「波形の形」が直前に使った AS110NoiseTest の DC のまま残っていたため(移植前のアプリは形を送らず本体の設定を使う作り)。人と相談して、接続時に三角波(対称 50%)を送るようにした(`Wf1973ContinuousSession.Connect(GeneratorWaveform)` を wrapper に追加。SPEC.md)。直した後の確認が上の表。

未確認:
- 出力中(PC_go の後)に「確認」で形を送り直したときの出力の乱れ。確かめたのは出力 OFF のときだけ
- 再押下で処理中の出し直しを打ち切る動き(コマンドの間に次の押下が入る場合)。実機では 1 回の出し直しが 3〜5ms で終わり、人の連続押下では重ならなかった。模擬では互換テストで確認
- WAVE LOGGER X での操作、NR-X(USB)、旧 WAVE LOGGER で見つからないときの LOGGER X への自動切り替え
- LOGGER 側でファイルを閉じたとき・LOGGER を閉じたときの扱い、「雛形を削除」「状態確認」ボタン、アプリ終了時の READY LED 消灯
- Arduino の再起動(`DIAG_BOOT`)、定期応答だけが止まる場合(USB はつながったまま)
- 発行した exe を別の PC で動かすこと
- 波形の振幅・周波数・位相の値そのもの(NR-500 で記録しての照合はしていない。目視だけ)。旧アプリの値(10.2Vpp・0.02Hz)は負の電圧が出るので、`Wrappers/Instruments/docs/WF1973実機確認.md` の連続の確認は 5.1Vpp・オフセット 2.55V に変えて行っている
