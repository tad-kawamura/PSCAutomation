# ver3の適用・操作手順

AS110AllCheckとして整理した配置に合わせ、ソリューション名と資料の参照先を更新しています。

AS110 ver3 / 2026-10-19

【適用】
1. 旧プロジェクトはそのまま残し、このフォルダを別の場所へ展開します。
2. AS110AllCheck.slnをVisual Studioで開きます。
3. 既存環境のNI-VISAの参照を確認し、リビルドします。
   VISA参照のパスは元のプロジェクトのままです。見つからない場合は
   これまで使っていたIvi.Visa.Interop等の参照を指定し直してください。
4. 元の「雛形」フォルダから、LOGGER用.xdt/.ydtと各型式の参照波形.xybをコピーします。
   LOGGER雛形は拡張子ごとに1件です。データ取りは2ms・6500点に設定してください。
   同梱の雛形.xlsxは、添付AS110-035のExcelです。
5. firmware/AS110M5Stack/AS110M5Stack.inoをM5Stack Basic V2.7へ書き込みます。
   Arduino IDEの場合：ボードM5Core（esp32 3.x。古い版ではM5Stack-Core-ESP32）、ライブラリM5Unifiedを選びます。
   準備の詳しい手順は m5stack-arduino-ide-setup.md を参照してください。
   PlatformIOの場合：firmwareフォルダのplatformio.iniを使用します。
6. 外部通電確認の無電圧接点をG26-GND間へ接続します。
   G26はコード冒頭のNF_PINで変更できます。外部電源は接続しません。
   接点開放=非通電、GNDへ導通=通電。3.3Vの内部プルアップを使います。
7. M5StackをUSBで接続し、PCアプリを起動します。

【操作】
接続確認→スタンド選択→モード選択。
データ調整／データ取りでは型式を選ぶと対応.xybを読み込みます。
参照波形のファイル名に完全な型式を含めてください（AS110-116B350等）。
型式欄が初期選択のままなら「型式を適用」を押すと読み込みます。
動き検査では従来の参照波形の一覧も使えます。
データ調整でも測定前に型式とS/Nを設定します。
未保存の測定を破棄して型式・S/Nを変更するには「設定変更（測定を破棄）」を使います。

M5Stackのボタンは、押して離したときに操作します。
動き検査：A=測定開始、B/C=未使用。保存・Excel転送・S/N設定は不要。外部接点の開発用模擬切替はREADMEの「動き検査と開発者モード」を参照。
データ調整：A=データ調整、B=Excel転送、C=未使用。
データ取り：A=データ調整、B=Excel転送、C=保存。
一式保存後：A=+30mA、B=漏れ試験実施、C=合格。
PC画面にも同じ操作ボタンがあります。

発振器は接続した機種に合わせ、次の設定を使用します。両機種とも三角波で、出力負荷は本体設定を使用します。

| 機種 | 動き検査 | データ調整／データ取り | 振幅・オフセット・周期数・開始位相 |
| --- | --- | --- | --- |
| WF1973 | 0.2Hz（2.5秒） | 0.04Hz（12.5秒） | 10.2Vpp、0V、0.5周期、開始位相0° |
| SDG1032X | 0.4Hz（2.5秒） | 0.08Hz（12.5秒） | 5.1Vpp、+2.55V、1周期、開始位相270° |

WF1973は0.5周期を設定できるため、半周期設定を使用します。本体に270°などの設定が残っていても影響しないよう、波形準備時に開始位相0°を明示的に設定します。
SDG1032Xだけは0.5周期を設定できないため、周波数2倍・振幅半分・オフセット+2.55V・開始位相270°により、0 → +5.1 → 0Vの山を1周期で出力し、従来の出力時間と傾きを維持します。
SDG1032X設定の参照元はAS110BoltCheckのコミット `58746ceb69285f4e5b2be94361cb153c19052b91`（`As110/As110MotionTest.cs`）です。参照元の実機確認記録はSDG1032Xについてのものです。本アプリの変更後は、両機種の実機で出力範囲・傾き・出力時間・開始終了と待機時の0Vを確認してください。
通電確認による開始制限は動き検査だけです。開始後の接点開放では停止しません。

測定終了で最新1回分を一時保存し、BでExcel転送します。
再測定すると前回の転送・保存・漏れチェック状態を無効にします。
データ調整からデータ取りへの切替では、同じ型式・S/Nの最新測定を維持します。
Excelのsheet1シートのE21とL21の両方がOKなら「保存します」と表示します。圧縮5は表示・PDF用であり、同じ番地に判定式はありません。
この通知はマウスでOKを押さず、M5StackのCでそのまま保存できます。
データ取りでは転送後も約1秒ごとに判定セルを確認し、両方OKならC「保存」を緑で有効にします。NG・空欄・計算中・判定取得失敗では無効です。PCとM5Stackの状態欄に判定状態と保存を止めている理由を表示し、PCログの「Excel判定」「保存許可」にセル値・工程条件を記録します。保存時にも再計算して判定を確認します。別の構成の雛形を使う場合は転送設定の「判定セルのシート（E21・L21）」を指定してください（既定sheet1）。

正式保存はExcel/PDF/LOGGERの3種類。途中失敗では保存済みとしません。
同じ番号で保存を再試行します。保存失敗中の再測定は止めます。
Excelを手動で閉じてしまった場合は、最新の一時データから再転送できます。
LOGGER一時保存の失敗では、BまたはPC画面で再試行します。
点数不足・未対応形式は無効な測定として通知し、再測定可能に戻します。

漏れチェックは正式保存後だけ。A「+30mA」で従来と同じDC+5V出力だけを開始し、出力を保持します。B「漏れ試験実施」はAの出力開始後に有効になり、LOGGERを前面に表示して現在の同じ雛形で収集を開始します。収集開始から10秒後に出力をOFFにしてLOGGERへ停止を要求し、完全停止を確認します。Windowsが前面切替を拒否した場合はログへ表示します。
漏れチェック結果をExcelへ転送・正式保存しません。
開始失敗・出力異常・アプリ終了時も発振器とLOGGERの停止をそれぞれ試みます。停止失敗や停止確認のタイムアウトでは正常完了とせず、機器を確認してから再試行します。
実施済みはLOGGER収集開始から10秒経過し、出力停止・LOGGER完全停止が正常終了してから記録します。再試験はAから操作します。出力待機中に再測定へ戻る場合や接続・雛形のリセット、アプリ終了時も出力を停止します。漏れの合否判断は人が行います。
C「合格」は一式保存＋漏れチェック1回以上、出力停止後に有効です。
合格では対象Excelを閉じたことを確認→完了記録→S/Nを1加算します。
保存後に再測定する場合はPC画面の「再測定へ戻る」から戻ってAを押します。

【保存先】
指定したフォルダの下にExcel、PDF、LOGGERを作ります。
同じ階層に「完了記録.txt」を追記します。
ファイル名例：AS110-035_SN74233_20261019_6500.xlsx
日付は測定開始時のWindows日時です。PDF・LOGGER・Excel内の日付を統一します。
完了番号は型式や日付によらずS/Nだけで保護します。
完了記録.txtは保存先と一緒に維持してください。
別の保存先フォルダを指定すると、そのフォルダの完了記録を使います。
同時起動による保存・完了記録の競合はロックで止めます。

完了番号のやり直し：PCの「完了番号の保護解除」→対象S/Nを入力。
解除日時を記録し、元のファイルは残します。
次の番号で作業を始める前に、測定開始S/N欄へ解除した番号を入力して再測定してください。
現行S/Nの再保存は、この起動中にアプリ自身が作成したファイルを更新します。
他の同名ファイルは停止通知します。解除済みS/Nの再測定時は更新できます。

【Excel雛形と転送設定】
標準：CH1=電流、CH2=圧力、6500点、5点平均→1300点。
sheet1!A4へ電流、B4へ圧力を書き込みます。
XDTはLOGGERのスケーリング／移動平均設定を読み取ってから圧縮します。
添付データでは電流は平均なし、圧力は7点移動平均です。
圧縮5の図形内の型式・供給圧力・S/N・測定日を書き換えます。
型式別圧力：035=539、015=588、135B=490、006=588、116B=490、116B350=350 kPa。

判定式・規格値は既存のExcel雛形を使用し、自動変更しません。
型式別の判定規格が異なる場合、対応するExcel雛形を
「AS110-015.xlsx」のような型式名で雛形フォルダへ置くと優先します。
共通雛形は「雛形.xlsx」です。同梱の共通雛形の判定式はAS110-035のものです。

NR-XのYDTはバイナリを推測せず、LOGGERの標準CSV一時出力を介して転送します。
CSVのスケーリング・平滑化設定はLOGGER側で使用する設定に従います。
実機ではCSV値とLOGGER表示の一致を初回確認してください。
CSV列はCH番号／電流・圧力の見出しで特定し、特定できなければ停止します。
その場合は「転送設定」でNR-Xの電流・圧力CSV列番号を指定します（1始まり）。
NR-XのCSVからは移動平均を重ね掛けせず、5点平均だけを行います。
YDTそのものは正式なLOGGERデータとしてそのまま保存します。
