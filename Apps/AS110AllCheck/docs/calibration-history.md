# 校正記録の保存（2026-11-02改訂）

当初（d80bef7）は機器識別名の入力、スタンド・型式・機器識別名ごとの前回値の呼び出しと再利用、校正日の確認を備えていた。ユーザーの想定は「入力したスケーリングの値を雛形へそのまま反映する」ことだけであり、記録はスタンドごとのPCに保存されるためスタンド名も不要との指示により、次のとおり簡略化した。

## 操作

1. モード・スタンドを選ぶと校正画面が開く。初回値は電流がスタンド公称値、圧力が当該モードの雛形の値。
2. CH1電流・CH2圧力の低点／高点の電圧と実測値（8項目）を入力し、「適用」を押す。入力中のEnterでは適用しない。
3. 作業用XDTへ値を反映してLOGGERで開き、停止状態を取得できた後に記録を追記する。記録の保存完了までは校正適用済みとしない。
4. 「電流・圧力の校正値を変更」では、現在適用している値が入った状態で校正画面を開く。

機器識別名の入力、前回値の呼び出し・再利用、校正日の確認はない。メイン画面には適用日時と適用値を表示する。

## 保存先・形式

`%LOCALAPPDATA%/AS110AllCheck/校正記録.txt`

- アプリ本体と別に保持する。再起動やexeの差し替えでは削除しない。Windowsユーザーごとの保存先であり、別PCや別ユーザーへ自動共有しない。
- UTF-8（BOMなし）、1行1JSONのテキスト。適用のたびに1行追記しディスクへフラッシュする。過去の行は読み直さず変更しない。
- 1行の内容は `AppliedAt`（適用日時、時差つき）、`Calibration`（`Current`・`Pressure` それぞれの `Input1`・`Output1`・`Input2`・`Output2`）、`Version`（2）。スタンド名・機器型式・機器識別名は記録しない。
- 改訂前の形式（Version 1、機器識別名などを含む行）が残っていても、そのまま保持して後ろへ追記する。
- 書込み中は他プロセスの書込みを排他する。保存できない場合はエラーを表示し、測定を開始させない。
- 自動削除は行わない。10年保管に備えて、このファイルを定期的にバックアップする。GitHubには送信しない。
