適用手順
1. 現在のプロジェクトをバックアップしてください。
2. 上記2つの.csファイルを同名のファイルと置き換えてください。
   片方だけの置き換えは行わないでください。
   バックアップの.csファイルはプロジェクト外へ保管してください。
3. Visual Studioでリビルドしてください。
4. 起動・接続確認、通電／非通電時のボタン操作、連続測定、
   一時的な受信停止からの復帰、アプリ終了を実機で確認してください。

構成
添付された20261016.zipの全ファイルを収録しています。
ArduinoConnection(4).csを基に、名前空間をAS110BoltCheckへ合わせました。
雛形フォルダ、Arduinoスケッチ、VISA DLLは元のZIPにも含まれていません。
既存の配置・参照設定を利用してください。

変更内容
ArduinoConnectionはCOM検索、接続、送受信、通信エラー通知を担当します。
NF:0／NF:1の解釈や定期通知の頻度の判断は行いません。
DisconnectAsync、送信エラー時の切断通知、終了処理との競合対策を取り込みました。
As110ArduinoProtocolへ500ms周期の受信監視を移動しました。
RX_STALE／NF_STALE／RX_RECOVERING／RECEIVINGの状態記録と、
正常復帰時に異常ログを終了へ進める処理をこちらで行います。
共通通信クラスのCOM状態・受信途中・読取遅延の診断は残しています。

維持する条件
・定期受信の途絶は1秒で診断ログへ記録。
・NF状態は1秒以内の受信情報を測定許可に使用。
・NF状態を3秒以上受信できない場合の警告。
・受信復帰後は1秒の継続受信を確認。古い開始要求は破棄。
・異常前1分をメモリ保持し、復旧後30秒まで同じ異常ログへ記録。
・専用受信スレッド、115200bps、DTR有効、既存の通信タイムアウト。
発振器設定（0.5周期の設定を含む）、LOGGER、GUI、雛形関連は変更していません。
Arduinoスケッチの書き換えや新規.csファイルの追加は不要です。

確認結果と制限
変更した2クラスの呼び出し関係、名前空間、監視の移動先を確認しました。
ZIP内のその他のソース・設定ファイルは元の添付ZIPとバイト単位で一致します。
