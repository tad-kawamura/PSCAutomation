# データ調整のS/N不要化・M5Stack文字サイズ（2026-10-28）

ユーザーより、前回版をビルドしてデータ調整も良さそうとの確認報告を受領。今回は追加仕様として、データ調整の正式保存・S/N設定は使用しない。型式選択・測定・Excel転送による確認は継続し、そのための内部一時ファイルは維持する。

- S/N入力欄はデータ取りでだけ表示・有効化する。データ調整の設定時は入力欄を読まず、工程のS/Nを空にする。データ取りへ戻ると、保持した入力欄の番号を設定して調整時の結果を無効化する。
- データ調整のPC状態欄は「保存・S/N設定なし」、M5StackはS/N欄非表示、ExcelのS/Nは「-」とする。正式保存・完了操作は従来どおりデータ取り専用。
- M5StackはefontJA_16を1.125倍し18px相当にする。枠を超えるボタン名のみ幅に合わせ縮小する。16pxは初期移行時のスケッチに既に存在しており、選定理由や実機比較の記録はない。

確認：PCのReleaseビルド成功。Arduino CLIで `m5stack:esp32:m5stack_core`（M5Stack 3.3.10、ローカルM5Unified/M5GFX）向けコンパイルも成功。スケッチ966499バイト、静的RAM26840バイト。工程検証にS/Nなしの型式選択・同じ型式の再設定・データ取りへの切替時の結果無効化を追加し成功。画面ロジック検証でも、不正なS/N入力をデータ調整で読まないこととS/N操作の無効化を確認。

未確認：今回変更後の機器接続による測定・Excel確認、M5Stackへの書き込みと18px相当の読みやすさ・折り返し。アプリ更新に加えスケッチの再書き込みが必要。
