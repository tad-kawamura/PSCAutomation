# Excel作業ブックの再利用（2026-10-30）

XDTのExcel転送待ちを短くするため、再測定開始時に前回の作業ブックを閉じず、次の転送で電流・圧力の測定値を列ごとにValue2で一括更新する。Excelインスタンスだけでなく、このアプリが作成した作業ブックも再利用する。他のExcel・ブックには接続しない。

型式・S/N・供給圧力・測定日が前回の転送と同じならヘッダ参照・更新を省略する。変更時は既存の文字単位の置換で変わった値だけを更新し、フォント・下線等を維持する。S/Nはデータ調整の「-」から数値への切り替えにも対応する。再計算の重複整理は今回行わず、既存の再計算・合否取得を維持する。

雛形のパス・サイズ・更新日時、データシート・開始セル、圧縮後点数が一致する場合に再利用する。異なる場合は前回ブックを閉じて雛形から作り直し、短いデータへ切り替えたときに前回の末尾を残さない。ユーザーが作業ブックを閉じた場合も次回転送で再作成する。再利用時に測定値の転送範囲へ数式が追加されていた場合は上書きせず転送を失敗にする。測定開始・転送開始時の工程無効化と、最新結果だけを正式保存できる条件は維持する。

## 実Excelでの計測

同梱の6500点XDTと雛形.xlsxを使用。別の専用Excelインスタンスと一時ブックで測定し、元のファイル・機器には書き込んでいない。転送値が更新されることを確認するため、一時コピーで電流の元波形を変更したXDTも使用した。

所要時間は読込・ブック作成または測定値更新・ヘッダ処理・既存の再計算・合否取得まで。画面の前面化・合否ポップアップ表示・LOGGERからの一時保存は含まない。

| 処理 | 時間 |
| --- | ---: |
| Excel起動を伴う初回転送 | 2485ms |
| 前回ブックを再利用した最初の転送 | 333ms |
| 従来と同様にブックを閉じて作り直す（Excel本体は再利用、3回） | 1708 / 1577 / 1547ms |
| ブック再利用（3回） | 334 / 308 / 324ms |

中央値は1577ms→324msで、約79%短縮した。このPC・雛形・XDTでの検証値であり、現場PCの実測値ではない。生ログはローカルの `bin/Release/net9.0-windows/ExcelReuseVerification_20261030.log` に保存（Git対象外）。アプリ画面のログには「測定値更新（ブック再利用）」「ヘッダ変更なし」を表示し、従来どおり最後に計算・判定時間と合計を表示する。

## 確認

- Debug/Releaseビルド成功。Releaseは警告・エラー0。Debugは既存のVISA参照のMSIL/AMD64不一致警告が1件。
- Verification全件成功。
- 実Excelで2600セル（1300点×2列）がXDT変換結果と一致。変更した波形で元の判定数式がOK→NGへ更新され、前回の合格を保持しないことを確認。
- 同じCOMブックの再利用、同一ヘッダの更新省略、S/Nの「-」→数値、型式・供給圧力・測定日の変更を確認。
- 圧縮点数変更時・雛形変更時の作り直し、前回末尾データの除去、手動で閉じた後の復帰、転送範囲の数式保護を確認。
- 既存の実Excelテストでヘッダの書式、結果シートの選択・復元、元の判定数式と転送後のOK/NG/空欄監視を確認。
- 実ExcelとMainFormの既存テストで、判定・処理中・転送無効化に応じてPC保存ボタンとM5Stack C許可ビットが連動することを確認（M5Stack実機は未接続）。

再実行：

```powershell
dotnet run --project Tests/ExcelHeader/ExcelHeaderTests.csproj -c Release -- "bin/Release/net9.0-windows/AS110AllCheck.dll" "雛形/雛形.xlsx" --reuse "雛形/AS110データ調整・データ取り用.xdt"
```
