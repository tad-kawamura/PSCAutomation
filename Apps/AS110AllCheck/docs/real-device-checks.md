# 実機で確認することの一覧(ver3.01 のあとに入れた分)

2026-11-16 作成。ver3.01 のあとに main に入れて、まだ実機で確かめていないもの全部を、現場で上から順に進められる並びにした。元は `Apps/AS110AllCheck/README.md`「確認」の未確認と、`specs/AS110AllCheck/SPEC.md` の各節。

- 書き方: 「すること → こうなれば良い」。★ は特に大事なもの(ほかで代わりに確かめられない・逃げ道が無い・1 回しか見られない)
- 結果は、確かめたらチェックを付け、違ったことはその行の下に書く。AI に伝えれば、ここと README「確認」に書き写す
- 機器が無い所で確かめたこと(ビルド・模擬)は README「確認」にある。ここに挙げたのはその残り

## 0. 準備

- 使う exe: main の今の版の試し版。現場の PC で作る(2026-11-16、人の決定。ver3.03 として発行するのは実機で確かめたあと)。ver3.01・ver3.02 のままでは、ここに挙げたものは入っていない(ver3.02 は 2026-11-18 に ver3.01 へ不具合の修正 1 件だけを足した版)
- `雛形` フォルダー: `AS110-035雛形.xlsx`・`AS110-015雛形.xlsx`・`AS110-116B雛形.xlsx`・`AS110-135B雛形.xlsx`(AS110-006 は 11. を見る)と LOGGER 雛形・参照波形
- ★ **現場 PC で新しい版を初めて起動する前に**、ver3.01 の転送設定の表・漏れ試験の欄(試験秒数・しきい値・最大値の下限・表示秒数)を写真に撮っておく(1. の引き継ぎを確かめるため。初めての起動でしか見られない)
- つなぐもの: M5Stack・WF1973(または SDG1032X)・NR-500(旧 WAVE LOGGER)。NR-X は 12.

## 1. 起動と接続

- [ ] ★ 初めて起動 → 転送設定の表と漏れ試験の欄が、ver3.01 のときと同じ値で出る(設定を `%LOCALAPPDATA%\AS110AllCheck\ver3.json` に写して引き継ぐ)
- [ ] 現場 PC の表示倍率(設定 → ディスプレイ → 拡大/縮小)で、メイン画面・合否の表示・転送設定・完了番号の保護と解除・漏れ試験の判定画面の文字が切れたり重なったりしない(開発 PC の 125% でだけ見た)
- [ ] 起動中にもう 1 つ起動 → 「このアプリはすでに起動しています」が出て、2 つ目は終わる。1 つ目は動いたまま
- [ ] 接続確認(M5Stack・発振器・NR-500)が今までどおり終わる。ログに「Arduino」でなく「M5Stack」と出る
- [ ] exe の隣の `Logs` に `画面ログ_yyyyMMdd.txt` ができ、画面のログ欄と同じ行が入っている
- [ ] 「開発者モード(接点模擬)」のチェックが出ない。`AS110AllCheck.exe --developer` で起動したときだけ出る

## 2. 校正(手入力)

- [ ] ★ (2026-11-18 から)接続確認のあと、モードを選ぶ前に校正画面が自動で開く(モード欄は押せない)。手で入れて「適用」 → exe の隣に `校正値\校正値_日付.txt` ができ、モードを選ぶと校正画面が出ずに雛形が読み込まれる。立ち上げ直すと校正画面が出ない(詳しくは 12. の 18.)

- [ ] ★ いつもの校正値を入れて「適用」 → 「ふつうの値から外れています」の確認が**出ない**(出たら、出た項目と値を書く。基準 `As110Calibration.FindUnusual` を現場の値に合わせる)
- [ ] わざと小数点を打ち忘れて(例: 5.524 → 5524)「適用」 → 外れた項目が並んで「このまま適用しますか?」が出る。Enter・Esc では適用されない
- [ ] ★ 校正したあと、動き検査 ⇔ データ調整 ⇔ データ取りとモードを替える → 校正画面が出ず、替える前と同じ換算で測れる(同じ物を測って値を比べる)

## 3. データ調整(型式ごとの転送・判定)

- [ ] M5Stack の A・PC の「データ調整」の両方で測定が始まり、いつもどおり終わって一時保存される(開始から 5 秒以内に LOGGER が「停止」以外になる。ならないと「LOGGER が測定を始めませんでした」で止まる)
- [ ] M5Stack から始めたとき、LOGGER の画面が Excel の上に出る(ver2.05 からの未確認)
- [ ] 型式ごとに、参照波形を選んで測定 → Excel 転送 → 合否が出る。判定が今までの Excel と同じ
  - [ ] AS110-015
  - [ ] AS110-116B(490 kPa)
  - [ ] AS110-135B
- [ ] 雛形の無い型式を選ぶと「…雛形.xlsx がありません」で止まる(`雛形` から 1 つ外して試す)

## 4. データ取り(保存まで)

- [ ] 保存先選択 → 測定開始S/N → 測定 → Excel 転送 → 保存が今までどおり通る。保存したファイル名の末尾に `_6500` が付かない
- [ ] 保存済みのファイルがある番号を測定開始S/N に入れる → S/N の下に橙色で「保存ファイルがすでにあります」(止まらない)
- [ ] 保存先フォルダー名の範囲の外の番号を入れる → 赤字「保存先フォルダーを確認してください」で「データ調整」を押せない(M5Stack の A でも始まらない)
- [ ] 前に保存した同じ S/N の PDF か Excel を開いたまま「保存」 → 閉じるファイルの名前が日本語で出て、保存先は保存の前のまま(今回の分は保存されない)。閉じてもう一度「保存」で保存できる
- [ ] ★ 作業用 Excel の判定セル(sheet1 の E21)に「OK」と打ってから「保存」 → 書き換えたところの一覧とパスワードの欄が出る。違うパスワードでは保存しない。正しいパスワードで保存でき、保存先の `Excel書き換え記録.txt` に残る(パスワードは README「作業用 Excel を書き換えたまま保存するときのパスワード」)
- [ ] 上のあと次の番号を測る → 作業用 Excel が雛形から作り直され、E21 が数式に戻っている
- [ ] データ取りで測って保存する前にモードを「データ調整」に替える → 「測定結果は破棄されます」の確認(既定「いいえ」)
- [ ] 保存のあと、保存先に空の `tmp` フォルダーが残らない

## 5. 漏れ試験

- [ ] 「+30mA」→「漏れ試験実施」→ 合格 →「合格」の一連が今までどおり(M5Stack から・PC から)
- [ ] ★ **不合格のあと「合格」を押せない**(PC の「合格」も M5Stack の C も)。やり直しは「+30mA」から。不合格はしきい値を小さく(例 0.1 kPa)するか、最大値の下限を大きく(例 600 kPa)して出す。終わったら欄を元に戻す
- [ ] 不合格・判定できないの判定画面が約 2 秒、合格が約 0.5 秒で閉じる。保存先の `漏れ試験記録.txt` に行が残る
- [ ] 試験秒数を 14 にして始める → 「長すぎます。…13 秒までにしてください」で始まらない
- [ ] ★ 合格のはずの試験が「判定できません(試験の終わりの … 秒は値を読めませんでした)」にならない(数回やって 1 回でも出たら書く。終わり際の 0.5 秒の決まりを見直す)
- [ ] 漏れ試験のすぐ後に M5Stack の A で次の測定を始める → 取り消されずに始まる(取り消されたら書く。SDG1032X も使うなら同じく)

## 6. 合格と次の番号

- [ ] 「合格」で S/N が 1 進み、最後S/N を超えると「最後のS/N まで終わりました」で止まる
- [ ] 合格のあと「アプリ終了」 → 聞かれずに終わる。保存済みで「合格」を押す前に「アプリ終了」 → 「アプリを終了しますか?」(既定「いいえ」)

## 7. AS110-116B350 の出荷データ(350 kPa)

- [ ] 490 kPa でロットを測り終え、レギュレーターを 350 kPa にして「供給圧力」で 350 kPa を選ぶ → 同じ S/N の測定が始められる(参照波形の照合で止まらない)
- [ ] データ調整 → Excel 転送 → 保存 → 「完了」で次の S/N へ。M5Stack は保存後 C=完了
- [ ] 保存先の中に `出荷データ(350kPa)` が最初の保存のときにでき、Excel の見出しが AS110-116B350・350 KPa
- [ ] 490 kPa で完了していない S/N は測れない

## 8. 完了番号の保護と解除

- [ ] 490 kPa の保護を外す S/N に出荷データがある → 消去するファイルが並んだ確認(既定「いいえ」)。「はい」でファイルがごみ箱に入り、出荷データの完了も外れる。保存先が USB メモリーのときは完全に消える
- [ ] 測定中の S/N は「(測定中のため保護できません)」でチェックを付けられない

## 9. 異常時

- [ ] ★ 測定待ちのとき M5Stack の USB を抜く → 「M5Stack の通信が途切れました」が 1 回だけ出る。発振器の出力が止まる。挿し直して「確認」→ 校正値と型式を入れ直せば測れる
- [ ] 漏れ試験の途中で M5Stack の USB を抜く → 日本語の中断の知らせ(英語の「A task was canceled.」でない)。漏れ試験記録に「中断」の行
- [ ] 保存先選択・転送設定などの画面を PC で開いている間、M5Stack のボタンが押せない表示になり、押しても何も起きない。閉じると戻る
- [ ] 発振器の電源を切る → 「次にすること」に「発振器の応答がありません…」(「LOGGER が未接続」でない)。NR 本体を切ったときは「NR 本体を確認できません…」
- [ ] LOGGER の一時保存に失敗したら(出せたら): 「一時保存を再試行」で今回のデータが取り込まれる。「確認」を挟むと「一時保存できなかった測定は破棄しました」

## 10. 終了と後片付け

- [ ] 測定・漏れ試験の途中に × → 「アプリを終了しますか?」(Enter・Esc・× では終わらない)
- [ ] タスク マネージャーでアプリを強制終了 → 起動し直すと、残った一時フォルダーと画面に出ていない Excel が片づく(ログに出る)。画面に出ている Excel は閉じない
- [ ] 終わったあと WAVE LOGGER(`NRWL.exe`)が残らない

## 実機を見てから決めること(結果を書いておく)

確かめるだけでなく、値を見て AI と決め直すもの。

- 漏れ試験の終わり際の 0.5 秒(5.)。値の届き方が 0.5 秒以上あくなら見直す
- 漏れ試験の後の最初の測定開始の 1 秒の期限(5.)。取り消されるなら、漏れ試験の後に波形の設定を送り直しておく
- LOGGER が測定を始めるまで待つ 5 秒(3.)
- ふつうの校正値の範囲(2.)
- NR-500 の電圧の平均の秒数(1 秒。12. の 15.)、Start を待つ上限(5 秒)、7351E の外れの知らせ(① ±1 mA・② 25 mA 未満)。値を見て決め直す
- 一時的な通信エラー 1 回で校正が外れる(SPEC 区切り 4「直していないこと」)。現場で困るほど起きるか
