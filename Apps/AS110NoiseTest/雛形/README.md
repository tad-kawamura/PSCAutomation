# 雛形(2026-11-03)

アプリが使う 2 つの雛形。どちらもリポジトリに入れる(`.gitignore` で `雛形/*.xdt`・`雛形/*.xlsx` だけ例外にしてある)。

| ファイル | 用途 | 出どころ |
|---|---|---|
| `AS110ノイズ測定用.xdt` | LOGGER で `OpenFile()` して記録設定(20 ms・2000 点=40 秒・4CH・スケーリング)を読み込む雛形 | 学習データ `2026.06.12_不具合返却品/SN60226/AS110_035_不具合返却品_SN60226_10mA_20ms_440kPa.xdt` をバイト単位でそのままコピー(p-p 1.1 kPa、無色の 1 本) |
| `AS110ノイズ測定_雛形.xlsx` | 測定結果を書き込む Excel の雛形。新規作成時はこれをコピーし、既存ブックへは追記する | `Tools/ExcelTemplate/make_template.py` で生成(学習データの Excel を参考に改良) |
| `型式一覧.txt` | 画面の「型式」の一覧(1 行 1 型式。空行と `#` で始まる行は読まない)。型式が増えたら書き足す(発行し直し不要) | 2026-11-05 作成。最初は `AS110-035` だけ |

## 雛形 xdt
- チャンネル定義は 1 月・6 月の学習データとも同じ: CH1 電流(1 V → 6 mA)、CH2 供給圧力(4.4 V → 440 kPa)、CH3 制御圧力(4.394 V → 439.4 kPa)、CH4 「指令」(スケーリングなし)
- 1 月と 6 月の xdt でヘッダが違うのは、日時と LOGGER の表示範囲(目盛)・カーソル位置だけ。記録設定は同じなので、新しい方(6 月)を採用した
- 中の測定データ(SN60226 10mA の 40 秒)は記録を始めれば置き換わる。雛形のスケーリングを変えるときは `Wrappers/LoggerFiles` の `XdtScalingEditor` を使う
- 作り直すとき: 学習データの任意の xdt を `cp` するだけ(`Wrappers/LoggerFiles/docs/xdt形式解析メモ.md` の構造で、どのファイルも同じ設定)

## 雛形 Excel の構成
学習データの Excel(`NF弁ノイズ確認`: SN 行 × mA 列の制御圧力 PP 値、右に平均値、下に平均値・標準偏差、黄は条件付き書式 `>1.39`、赤は手動塗り)を基に、
アプリが自動記入でき、日をまたいで追記しても壊れないように次を変えた。

| 変更 | 理由 |
|---|---|
| 平均値を右側の列ではなく別シート `平均値` に(同じ行番号) | 1〜35 mA を全部持つと 70 列を超えて見づらい |
| 赤を手動塗りではなく `赤判定` シートの「赤」文字 + 条件付き書式に | 赤を数式(赤の数・判定)から数えられる。人が訂正するときもセルを消す/書くだけで色が追従する |
| mA 列を 1〜35 の固定列(見出しは数値、表示だけ `mA` 付き) | 開始/刻み/終了 mA が可変でも列を探せる(見出しの値と一致する列に書く) |
| 平均値・標準偏差・最大の集計行をデータの**上**(4〜6 行目)に | 下に置くと追記で位置が動く。1007 行目まで集計する |
| `測定日`・`備忘録` 列、`最大p-p`・`黄`・`赤`・`判定`・`備考` 列を追加 | 日をまたいだ追記と、1 行で合否が分かるように。`合計` 列(PP の合計)は意味が薄いので廃止 |
| `型式` 列を追加(2026-11-05、暫定) | 画面で型式を選ぶようにしたため。行のキーを型式・SN・備忘録にした。Excel のファイル名にも型式を入れるので、どちらか一方に絞るかは使ってみて決める |
| `詳細` シート(1 測定 1 行、全チャンネルの平均・p-p、赤の根拠、xdt ファイル名) | 供給圧力など主表に出さない値を残す(specs/AS110NoiseTest/SPEC.md の方針) |
| `設定` シート(判定しきい値・測定条件) | アプリが使った値を記録する。黄の条件付き書式はここの C3 を参照 |
| 名前定義(`PP_Header` など) | アプリがセル番地を直書きしないで済む |

### シートと位置(アプリ側の契約)
行 8 以降がデータ。**PP値・平均値・赤判定の 3 シートは同じ行 = 同じ測定(型式・SN・備忘録)**。100 行分の罫線・数式を入れてある(足りなくなったら上の行をコピー)。

| シート | 列 | 内容 | 書くのは |
|---|---|---|---|
| `PP値` | A 測定日 / B 型式 / C SN / D 備忘録 | 行のキー(型式・SN・備忘録)。SN が空の最初の行が次の追記先 | アプリ |
| | E〜AM = 1〜35 mA(見出し行 7 は数値 1〜35) | CH3 制御圧力の p-p [kPa](0.1 kPa に丸めた値) | アプリ |
| | AN 最大p-p / AO 黄の数 / AP 赤の数 / AQ 判定(OK・黄・赤) | 数式 | — |
| | AR 備考 | 自由記入 | 人 |
| `平均値` | A〜D | PP値シートの同じ行に数式で追従 | — |
| | E〜AM | CH3 制御圧力の平均 [kPa] | アプリ |
| `赤判定` | A〜D | PP値シートに追従 | — |
| | E〜AM | 赤なら「赤」、それ以外は空白。PP値シートの同じセルが赤くなる | アプリ(人が訂正可) |
| `詳細` | A〜W(1 行目が見出し、2 行目から追記) | 測定日時・型式・SN・備忘録・指令/実測電流・CH1〜CH4 の平均と p-p・CH3 の最小/最大・判定・赤の根拠(A/B/C)・台地連続数・低周波比・段差・t 値・xdt ファイル名 | アプリ |
| `設定` | C3〜C8 | 黄しきい値、台地 kPa/サンプル数、低周波比、段差 kPa/t 値(既定値入り) | アプリ(実行時の値を上書き) |
| | B11〜 | 測定条件(Ps、サンプリング、電流許容・上限、待ち時間、雛形 xdt) | — |

色: **黄 = 条件付き書式**(`設定!C3` 以上、既定 1.4 kPa。赤判定シートが「赤」のセルは除く)。**赤 = 赤判定シートの「赤」**(黄より優先)。
`判定` 列と `詳細` の判定列も同じ色が付く。

名前定義: `PP_Header`(`PP値!E7:AM7`)、`PP_FirstRow`(`PP値!A8`)、`Mean_Header`、`Mean_FirstRow`、`Red_Header`、`Red_FirstRow`、`Detail_Header`(`詳細!A1`)、
`Setting_YellowPp`〜`Setting_StepT`(`設定!C3〜C8`)、`Condition_FirstRow`(`設定!B11`)。

### 既存ブックへの追記(`Excel/NoiseResultWorkbook.cs` の動き。Excel の操作は `Wrappers/Excel` の部品)
1. `PP値` で **型式・SN・備忘録が同じ行** があればその行、無ければ C 列(SN)が空の最初の行(日付はキーにしない。人の Excel でも「SN60260再調整後」は 6/15〜6/16 にまたがって 1 行だった。別の行にしたいときは備忘録を変える)。新しい行なら測定日・型式・SN・備忘録を書き、以後は変えない
2. 見出し行 7 から指令 mA と一致する列を探す(`PP_Header`)
3. `PP値`(p-p、0.1 kPa 丸め)・`平均値`(0.01 kPa 丸め)・`赤判定`(赤なら「赤」、違えば消す)の同じ行・同じ列に書き、`詳細` の末尾に 1 行追記する。同じ SN・備忘録・mA を測り直すと上書き
4. 101 行目以降が必要になったら、上の行をコピーして(数式・罫線を引き継ぐ)値だけ消してから書く
5. 1〜35 mA 以外の指令(小数の刻みなど)は列がないので例外にする(必要になったら列を挿入する仕様にする)
6. 保存は `Save()` を呼んだとき。Excel は非表示で起動し、`LeaveOpenForUser()` を呼ばなければ終了時に閉じる

2026-11-03 に `Tools/ExcelWriteCheck` で学習データ 95 本(SN60226・SN60260 の 3 条件・ヨーク165 SN1)を書き、人の Excel と照合: p-p と赤は全件一致。
制御圧力平均は人が LOGGER 表示(4 桁切り捨て)を転記していたため末尾 1 桁が違うことがある(ヨーク165 SN1 17mA の 228.8 は 288.8 の転記ミス)。1 本あたりの書き込みは 50 ms 程度。
