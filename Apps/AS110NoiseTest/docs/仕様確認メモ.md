# AS110ノイズ測定アプリ 仕様確認メモ(2026-11-02 時点)

> 移植前(旧リポジトリ AS110NoiseTest、`c3e75b3`)に書いた記録。文中のパス(`Libraries/`・`Devices/`・`Conversion/`・`CLAUDE.md`)は移植前のもの。移植後の置き場は [README.md](../README.md)「移植前との対応」、決定事項の正本は [specs/AS110NoiseTest/SPEC.md](../../../specs/AS110NoiseTest/SPEC.md)。

## 決定事項
- C# 新規リポジトリ `AS110NoiseTest`。AS110AllCheck(GitHub tad-kawamura/AS110AllCheck)の wrapper 群を流用する
- 機器: WF1973(発振器、DC オフセットで電流指令、**1V = 6mA**)、ADCMT 7351E(DMM、**USB のみ**、C# から実電流を読む)、KEYENCE NR-500(データロガー、WAVE LOGGER COM で制御)
- 電流制御: 7351E の実測値をフィードバックして WF1973 のオフセットを微調整。許容 **±0.1mA**。**上限 35mA**
- 電流を合わせてから記録開始までの待ち時間: **まず 1 秒**(やりながら調整)
- 記録中(約 40 秒)は WF1973 の指令を固定し、その間に電流がずれても問題としない。±0.1mA を満たす必要があるのは合わせ込み完了(記録開始前)の時点だけ(2026-11-03 決定)。実機では合わせ込み後の誤差は最大 0.035mA、2 秒保持中の変動は 0.002mA 以内(`7351E実機確認.md`)
- 電流ステップ(開始 mA / 刻み / 終了 mA)は **可変**
- 操作フロー: 最初に SN・備忘録・開始/刻み/終了 mA・保存先を指定 → 開始クリック → 最後の電流まで自動で変化・自動保存・自動測定 → Excel に自動記入
- LOGGER チャンネル(1始まり): **CH1=電流、CH2=供給圧力、CH3=制御圧力、CH4=WF1973 の指令電圧**(1V = 6mA、スケーリングなし。2026-11-03 実機で CH1 と同じ値を示すことを確認。CH1 は 7351E 側、CH4 は WF1973 の出力をそのまま見ている)
- p-p 判定対象は CH3 制御圧力の max−min(Excel の PP 値と完全一致を確認済み)
- Excel 出力: アプリが新規作成も、既存ブックへの追記も両方できるようにする(日をまたぐため)。雛形は `雛形/AS110ノイズ測定_雛形.xlsx`(2026-11-03 作成、`Tools/ExcelTemplate/make_template.py` で生成。構成とアプリが書く位置は `雛形/README.md`)。書き込みは `Excel/NoiseResultWorkbook.cs`(Excel COM 遅延バインディング、AS110AllCheck と同じ方式)。行は SN+備忘録で決め、日付はキーにしない(人の Excel でも「SN60260再調整後」は 6/15〜6/16 で 1 行)。測定日は行を作った日。同じ SN・備忘録・mA を測り直すと同じセルを上書きし、赤判定も消す/書き直す
- 供給圧力(CH2)はデフォルトでは主表に出さないが、全チャンネルの mean/p-p を詳細シートに残す方針(雛形の「詳細」シート)
- 平均値シートの制御圧力平均は 0.01 kPa に丸めて書く。人は LOGGER の表示(4 桁、切り捨て)を転記していたので末尾 1 桁が違うことがある(2026-11-03 の照合で確認。p-p と赤は全件一致)
- 雛形 xdt: `雛形/AS110ノイズ測定用.xdt`(2026-11-03 決定。学習データ 6 月 SN60226 10mA をそのままコピー。1 月と 6 月の xdt はチャンネル定義・記録設定が同じで、違いは日時と LOGGER の表示範囲だけ)
- **p-p の合否しきい値: 最重要。別途決める(宿題)**。設定値として外出しにしておく
- 7351E の接続ポート種別は **USBTMC**(VISA で通信、2026-11-03 実機確認)。詳細は `7351E実機確認.md`
- 7351E の設定は ADC コマンドで PC から行う。DCI・200mA レンジ固定・SLOW2・BUS トリガ(2026-11-03 実機確認)
- 対象は xdt のみ(NR-X / YDT は対象外、後で変わる可能性あり)

## 自動保存ループ(AS110AllCheck の WaveLogger.Automation で実現可能)
`OpenFile(雛形xdt)` → 電流設定・7351E で確認 → 1秒待ち → `StartSingleAcquisition()` → `GetState()` で停止待ち(雛形の記録時間で自動停止) → `SaveXdt(規則名)` → 次の電流

2026-11-03 に `Measurement/MeasurementSequence.cs` として実装(保存のあと集計 → Excel 書き込み → `CloseActiveFile` を追加)。待ち時間・タイムアウト・ファイル名規則・終了時の電流は `MeasurementSettings`。機器なしの模擬(`Tools/MeasurementCheck --sim`)で通した。実機は未確認(`測定シーケンス実機確認.md`)。
