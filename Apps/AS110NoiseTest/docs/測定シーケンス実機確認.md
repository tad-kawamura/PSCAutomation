# 測定シーケンス(設定 → 自動ループ)と実機確認の手順(2026-11-03)

> 移植前(旧リポジトリ AS110NoiseTest、`c3e75b3`)に書いた記録。文中のパス(`Libraries/`・`Devices/`・`Conversion/`・`CLAUDE.md`)は移植前のもの。移植後の置き場は [README.md](../README.md)「移植前との対応」、決定事項の正本は [specs/AS110NoiseTest/SPEC.md](../../../specs/AS110NoiseTest/SPEC.md)。

`Measurement/MeasurementSequence.cs` が CLAUDE.md「アプリの動作フロー」2 を実装している。機器なしの模擬では通ることを確認した。
**実機(NR-500 + WAVE LOGGER、WF1973、7351E)ではまだ動かしていない。** このメモは、実機で何をどう確かめ、何を決めるかの手順。

## 構成
| ファイル | 役割 |
|---|---|
| `Measurement/MeasurementSequence.cs` | 1 電流ごとに OpenFile → 電流合わせ → 待ち → Start → 停止待ち → SaveXdt → 集計 → Excel。失敗・中断時は LOGGER を Stop し WF1973 を 0V・出力 OFF |
| `Measurement/MeasurementSettings.cs` | 待ち時間・タイムアウト・ファイル名規則・終了時の電流などの設定値(コードに直書きしない) |
| `Measurement/MeasurementPlan.cs` | 1 台分の入力(SN・備忘録・開始/刻み/終了 mA・保存先・Excel)。電流は 1〜35 の整数だけ |
| `Measurement/ILoggerDevice.cs` | シーケンスが使う LOGGER の操作(OpenFile / Start / GetState / Stop / SaveXdt / CloseActiveFile) |
| `Measurement/WaveLoggerDevice.cs` | 本番の LOGGER。`Libraries/WaveLogger.Automation`(AS110AllCheck からコピー)の `WaveLoggerSession` を包む |
| `Excel/INoiseResultWriter.cs` | 結果の書き先。本番は `NoiseResultWorkbook`(Excel COM)、確認ツールではコンソール出力に差し替え可 |
| `Tools/MeasurementCheck/` | 確認ツール。`--sim`(全部模擬)/ `--logger-only`(LOGGER だけ実機)/ `--real`(全部実機) |

### 1 電流の流れ(`MeasurementSequence.RunStep`)
1. `OpenFile(雛形/AS110ノイズ測定用.xdt)` 戻り値 0 を確認
2. `CurrentController.Regulate(mA)` で WF1973 を 7351E 実測 ±0.1mA に合わせる(上限 35mA は `CurrentControlSettings.MaxMilliamps`。`MeasurementPlan.Validate` でも弾く)
3. `SettleSeconds`(既定 1 秒)待つ
4. `GetState()` が停止(1 / 11)であることを確認 → `StartSingleAcquisition()` 戻り値 0 を確認
5. `StateReadDelayMilliseconds`(500ms)後から `GetState()` を 200ms ごとに読む。停止(1)から抜けたら記録中、1 に戻ったら記録終了。11 はエラー停止。10 秒たっても 1 のままなら「始まらない」、90 秒で終わらなければタイムアウト
6. `SaveXdt(保存先\AS110_035_<備忘録>_<SN>_<mA>mA_20ms_440kPa.xdt)` 戻り値 0・ファイルの存在・サンプル数 2000 を確認。同名があれば `_2`、`_3` を付ける(`OverwriteExistingXdt=false`)
7. `XdtNoiseAnalyzer.Analyze` → `NoiseResultWorkbook.Write` → `Save()`(`SaveExcelAfterEachStep=true` なので 1 電流ごとに保存)
8. `CloseActiveFile()` 戻り値 0 を確認(`CloseFileAfterSave=true`)
9. 保存した xdt の制御圧力の表示レンジを平均値中心に書き換える(`CenterControlPressureDisplay=true`、`XdtDisplayRange.Center`。雛形の 74〜84 kPa のままだと LOGGER で開いたとき線が画面の外に出るため。失敗しても警告だけで測定は続ける)

全電流が終わったら `FinalMilliamps`(既定 null = 0V・出力 OFF)。測定日時は保存した xdt のヘッダ(FILETIME)から取る。

### スレッド
VISA COM(7351E・WF1973)も LOGGER COM も「接続したスレッドから使う」前提なので、シーケンスは同期(呼び出しスレッドを止める)で書いてある。
`WaveLoggerSession.ShutdownAsync` は `await Task.Delay` をはさむため、確認ツールは WinForms の同期コンテキスト(`Application.Run`)の上で動かしている。
画面(WinForms)に組み込むときは、**専用の STA スレッド**(そのスレッドで機器を接続し、`Application.Run` でメッセージループを回す)でシーケンスを動かし、`Log` / `StepCompleted` を `Invoke` で UI に渡す。中断は `CancellationToken`。

模擬 LOGGER は雛形 xdt のデータ部だけ差し替えて保存する(CH1 = 模擬の実電流、CH3 = 電流ごとの波形、CH2・CH4 は雛形のまま)。
2026-11-03 に確認: 判定(無色・黄・赤)が波形どおり、xdt の CH1 が指令どおり、Excel の PP値・平均値・赤判定・詳細に書けて行の集計(最大 p-p・黄・赤・判定)が合う、追記(同じ SN・別の備忘録 → 別の行)、同名 xdt は `_2`、中断時の後始末、終了時の電流、範囲外(40mA)の拒否。

**ほかの LOGGER 画面は閉じておく**(wrapper は制御対象を一意に特定できないと止まる)。

#### 手順 2 で起きたこと(2026-11-03)
2 回目(WF1973 の USB 抜き差し後、16:33)は通った。WF1973 は iOpen 16ms で *IDN? に応答。詳細シートの CH4 が WF1973 の指令電圧と一致したので、**CH4 = 指令電圧**と判明(CLAUDE.md・仕様確認メモに反映)。詳細 の測定日時は列幅が足りず #### 表示になることがある(値は入っている)。--visible でも Excel はツール終了時に閉じる。実機確認.cmd は終了コード 1 でもバッチの %ERRORLEVEL% 表示だけなので、ログの エラー: 行を見る。
1 回目は 7351E の設定まで通ったあと `WF1973 を確認できません ... HRESULT = 80040000` で止まった(電流は流していない。終了コード 1)。
Windows は WF1973 を USB 機器として認識していた(ProblemCode 0)が、`viOpen` が 1 分以上ブロックしてから `VI_ERROR_SYSTEM_ERROR (0xBFFF0000)` になる状態で、USBTMC の通信だけ固まっていた。
イベントログでは 14:57・15:01 に PC が低電力状態(DRIPS)に入り、復帰時に WF1973・7351E・NR-500 の 3 台が再列挙されている。7351E と NR-500 は復帰後も動いたが WF1973 だけ固まった。
対処は **WF1973 の USB を抜き差し(または電源再投入)**(`pnputil /restart-device` は管理者権限が要るのでツールからはできない)。
教訓: 実機 PC のスリープ・モダンスタンバイを切っておく。アプリ側は WF1973 の接続失敗を即座に報告する(今の 2 秒タイムアウトは Open のブロックには効かない)。

### 4. 実機を見て決めること(決めたら `MeasurementSettings` の既定値と specs/AS110NoiseTest/SPEC.md を直す)
- `SettleSeconds`(1 秒で圧力が落ち着くか。LOGGER の CH3 の立ち上がりを見る)
- `FinalMilliamps`(終了時 OFF でよいか、何 mA かに置いておくか)。開始前の電流は、最初の電流に合わせる前は 0V(出力 OFF)のまま
- ファイル名規則をそのまま使うか(`XdtFileNamePattern`)
- `AcquisitionTimeoutSeconds` / `StartTimeoutSeconds`
- 7351E の BUS トリガのままでよいか(記録中は読まないので問題ないはず)
