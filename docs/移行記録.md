- namespace を `PSCAutomation.Wrappers.<箱>` にした(箱 = `Wrappers/` の下のフォルダー名)。アセンブリ名も同じ(`PSCAutomation.Wrappers.Common.dll` など)。アプリを移すときは `using` の差し替えで対応する。

AllCheck / NoiseTest の `Conversion/XdtReader.cs`(2 つは同一)は移していない。同じ入口を `XdtFile.cs` の `XdtReader` が持つ。アプリを移すときに次を確認する。

- `XdtInfo.Channels` が配列から `IReadOnlyList<ChannelInfo>` に変わった。`.Length` は `.Count`(または `ChannelCount`)に直す。
- **スケーリング無効の CH の扱いが違う**。旧版は無効でも 2 点から換算していた。新版は無効なら換算しない(メーカー CSV と照合済みの動き)。照合用の xdt 7 本では無効 CH の 2 点が恒等(倍率 1、ずれ 0)なので値は同じだった。無効にする前に別の 2 点が入っていた CH では値が変わりうる。
- 新版はスケーリング・移動平均の有効フラグが 0/1 以外なら例外にする(旧版は見ていなかった)。
