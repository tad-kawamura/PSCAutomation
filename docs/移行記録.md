- AllCheck: 元の AllCheck 版は `READER_ERROR` を異常種別に入れていなかった(SwitchController 版は入れていた)。統合版では `READER_ERROR` でも異常ログを保存し始める。
- `PcDelayObservation.Start()` は `PcDelayObservation.Start(ArduinoDiagnosticLog.Write)` にする(手順 2 のとおり)。
- `using PSCAutomation.Wrappers.Arduino;` と `using PSCAutomation.Wrappers.Common;` を足す。

### 動きが変わるところ

- **AS110BoltCheck**: AllCheck 版を使うので、発振器を解放するとき(`Dispose`)に出力 OFF を送るようになる(タイムアウト 500ms、失敗しても解放は続ける)。安全側への変更。
- **機器が 1 台もつながっていないとき**(AllCheck・BoltCheck・SwitchController): 元は VISA の検索が例外(`COMException`、VISA のエラー文)をそのまま投げていた。統合版は NoiseTest と同じく「該当なし」として扱い、「WF1973 を確認できません。電源、USB、NI-VISA を確認してください。」などのいつものメッセージの `InvalidOperationException` にする。3 アプリとも `catch (Exception ex)` で `ex.Message` を表示しているので、画面に出る文言が変わるだけ。
- **接続直後の初期化が失敗したとき**: 開いた接続を必ず閉じるようにした。元の NoiseTest は DC の準備に失敗すると接続を閉じずに残していた(COM オブジェクトの解放漏れ)。
- 送るコマンド・順番・タイムアウト値・エラーメッセージの文言(上の「該当なし」以外)は変えていない。

### アプリを移すときに直すこと

- `using PSCAutomation.Wrappers.Instruments;` を足し、アプリの `Generator/`・`Devices/` の発振器・DMM のファイルを消す。
- クラス名: AllCheck・BoltCheck の `Wf1973Session` → `Wf1973BurstSession`(`is Sdg1032XSession` の判定はそのまま使える)。SwitchController の `Wf1973Session` → `Wf1973ContinuousSession`(`MainForm.cs` のフィールドの型と `Connect()` の呼び出し)。
- SwitchController の互換テスト: `FakeInstrument` に `Address`・`TimeoutMilliseconds`・`Read()` を足す。
- NoiseTest: `Wf1973DcSource` と `Adcmt7351ESession` が `IOffsetVoltageSource` / `ICurrentMeter` を実装しなくなったので、アプリ側に包むクラスを置く(メンバーの名前と型は同じなので、そのまま渡すだけの数行)。`MeasurementSequence` と検査ツールはその包みを使う。`VisaUtil` は不要になる。
- 各アプリの csproj の NI-VISA 参照(`VisaInteropPath` と `ValidateVisaInteropPath`)は、Instruments を参照すれば要らなくなる。

### 旧 Verification の Excel 転送検査が A6 で止まっていた件(直した)

- 原因: 旧検証は「雛形の Sheet1 の A6 以降に前回の転送値が入っている」前提で、雛形の値と変換後の値を比べていた。同梱の `雛形.xlsx` は Sheet1(`xl/worksheets/sheet2.xml`)の A6 以降が空なので、`oldCells["A6"]` が `KeyNotFoundException` になっていた(旧 README の「66 行目で A6」)。値の入ったブックを前提に書いた検査を、値を消した雛形のまま登録したためと推測する(旧リポジトリの履歴では、雛形は最初のコミットから今の内容)。変換そのものの不具合ではない。
- 直し方: 比較の相手を、独立の参照値(`Fixtures/PC.bin`・`CR.bin`、メーカーソフトで出した全点の値)を 10 点おきに取ったものにした(許容差 0.0002、xdt 照合と同じ)。転送点数が 5,000 点であること、5,001 点目が空であることも確かめる。シート名からワークシートのパーツを引くようにした(旧検証は `sheet2.xml` 直書き)。
- 追加: 旧アプリの出力と比べる `--compare-old <xlsx>`。旧リポジトリの `…_変換_20261008_144212413.xlsx`(2026-10-08 に旧アプリが同じ PC / CR の xdt・既定設定で出力したもの)と、A・B・H・I 列の 6〜5005 行(20,000 セル)が文字列として一致した。

### 元と動きが違うところ

- 参照の返し方: 元は `Marshal.FinalReleaseComObject`(全部返す)。部品では `ReleaseComObject`(1 つ返す)にした。同じシートを別の経路で取ると .NET 側で同じ参照になり、全部返すとアプリが持っているシートまで使えなくなる(テストで再現した)。残りは `ExcelApplication.Dispose` の GC で返す。`ExcelViewer` は元どおり全部返す
- 切断とみなすエラーに `0x800706BE`(RPC_S_CALL_FAILED)を足した。Excel が落ちた直後の最初の呼び出しで出る(テストで確認)。元の AllCheck は 3 種類だけ
- `ExcelViewer`: 失敗したとき、Excel が実際に終わるまで(最大 10 秒)待ってから失敗を返す。元の `ExcelPresenter` は、失敗の直後にアプリが終わると Excel が画面の無いまま残った(単独の検査プログラムで 3 回とも再現)。失敗メッセージから XdtConversion 固有の一文(「変換済みのExcelファイルは保存されています。」)を除いた
- 開く: 無いファイルは Excel を呼ぶ前に `FileNotFoundException`。読み取り専用で開かれたときは、元はブックを開いたまま例外だったが、閉じてから例外にした
- 列への書き込み: 元(AllCheck)は電流・圧力の 2 列だけ。部品は何列でもよく、隣り合う列(開始行・点数が同じ)をまとめて書く。非数値は止める
- 後始末: Excel を終了する条件を選べるようにした(`ExcelQuitMode`。既定は AllCheck の「ほかにブックが無ければ終了」、NoiseTest は `Always`)
- メッセージは「雛形の形式が違います」を「ブックの形式を確認してください」にした(雛形以外にも使うため)

### アプリを移すときに直すこと
