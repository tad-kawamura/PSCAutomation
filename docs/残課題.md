## AS110AllCheck(来週、実機確認)

- 2026-11-05 に `Apps/AS110AllCheck` へ移した(`ExcelWorkSession` の部品への書き直し、ファームウェアの移動、NR-X は USB と Wi-Fi を残し SSID はアプリの設定クラス)。ビルドと機器なしの検査まで(`Apps/AS110AllCheck/README.md`「確認」)
- 実機確認: M5Stack・NR-500 / NR-X(USB・Wi-Fi)・WF1973 / SDG1032X をつないで、測定 → Excel 転送 → 正式保存 → 漏れチェック → 完了の一連。Excel の操作を部品に替えたので、転送・判定・保存・前面表示は特に見る
- M5Stack スケッチは 2026-11-05 に人が Arduino IDE で M5Stack Basic V2.7 へ書き込めた(手順は `Apps/AS110AllCheck/docs/m5stack-arduino-ide-setup.md`。スケッチは変えていない)。書き込み後の表示・ボタン・G26 接点・PC アプリとの通信は上の実機確認で見る
- LOGGER 本体ソフトの事前起動(2026-11-05 に追加。起動を画面準備と重ねる)の未確認: NR-X・WAVE LOGGER X・Wi-Fi での事前起動、両方の LOGGER が入った PC で種類を切り替えたときの破棄、旧 WAVE LOGGER の起動に 7〜8 秒かかる回での短縮幅(確認した回は本体の起動が 0.6 秒と速かった)
- 2026-11-06 に操作欄を変えた: モードを選ぶまで操作欄を隠し、保存先・S/N・保存・漏れ試験・合格はデータ取りを選んだときだけ出す。並びを型式・S/N → 保存先 → 保護解除 → ボタンにし、最後S/N(空は上限なし。超えたら測定開始を止める)を足した(機器なしで確認。実機の画面と合格後の S/N 加算は未確認)
- 2026-11-06 に続けて変えた(機器なしの検査のみ。実機は未確認): モード欄は未選択のあいだ赤字「未設定」。開始S/N・最後S/N は型式の下の行。合格は下段の左。窓は 760×800(スタンドのボタン 220 幅)。完了番号の保護解除はチェック一覧(保護中=チェックあり。外して確定で解除、付けて確定で再保護。保存先未選択はポップアップ)。保存先フォルダー名は「SN開始-最後」を含める決まりにし、選ぶと開始S/N(空か 1)・最後S/N(空)を自動入力、合わないときは赤字で警告して正式保存を止める。保存先選択時に Excel/PDF/LOGGER を走査し、完了記録に無い S/N を知らせて保護解除の画面で「記録なし」として保護できる(`Apps/AS110AllCheck/README.md`「操作・設定」、`Production/SaveFolder.cs`)。人が実機で触って問題点を見る予定
- 2026-11-06 にさらに変えた(機器なしの検査のみ。実機は未確認): データ取りの操作欄を 型式 → 保存先 → 開始S/N・最後S/N → 測定開始S/N → 保護解除 → ボタン の順にした。開始S/N・最後S/N は保存先フォルダー名から自動で入る表示専用(緑字・小さい字)で、人が入れるのは「測定開始S/N」(今から測る番号。途中再開もここ)だけ。空のあいだは赤字「入力してください」で測定開始を止め、Excel の事前準備も入力後に始める。フォルダー照合は測定開始S/N が範囲内かだけ(`SaveFolder.CheckRange`)。ボタン名は「完了番号の保護解除」→「完了番号の保護と解除」(保護も解除もできるため)
- 2026-11-06 に校正の流れを変えた(機器なしの検査のみ。実機は未確認): スタンド選択ボタンを廃止し、接続確認とモード選択の両方が済んだら校正画面「スケーリング」を自動で開く(キャンセル後は「校正値を入力」ボタン)。校正画面は現場の用紙と同じ縦型(電流・圧力の枠ごとに 1=低点・2=高点、計測値 V と表示値 mA/kPa)。初期値は雛形の値で前回値は呼び出さない。横軸拡大(門馬さんの隣のスタンドの 2 段)は廃止。校正記録は `%LOCALAPPDATA%` の 1 行 1 JSON をやめ、データ取りの保存先の `校正記録` フォルダーへ 1 件 1 ファイルの日本語テキストで残す(校正の適用と保存先の両方がそろった時点で書く)。NR-X(ydt)の校正は保留のまま(校正画面を出さず雛形の値のまま)。本体 NR-500 → NR-X、ソフト 旧 WAVE LOGGER → X、接続 USB 優先は元からコードどおりで変更なし(`specs/AS110AllCheck/SPEC.md`「校正の流れの変更」)。同日に「型式」の行と「型式を適用」も廃止し、型式は「型式（参照波形）」で選んだ .xyb のファイル名から決める形にした。「設定変更（測定を破棄）」は「校正値を変更」の右隣へ移した。実機で、モード選択→校正画面→適用→型式（参照波形）選択→測定→保存先選択→校正記録の作成を確認する
